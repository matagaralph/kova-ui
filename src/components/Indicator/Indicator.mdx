## Best practices

- Use `LoadingIndicator` for short, indeterminate waits, such as loading a list or a button action.
- Use `CircularProgress` for longer tasks like uploads. Pass `progress` when you know real progress, and set `done` when the task finishes so the simulated timer resolves.
- Use `LoadingDots` for typing or streaming states, such as a pending chat response.
- Let indicators inherit `font-size` and `color` from surrounding text, and only override `size` or the CSS variables when needed.
- Avoid showing an indicator for near-instant operations, where it only adds flicker.

## Accessibility

- Indicators render plain `div` and `svg` elements with no role or label, so screen readers don't announce them on their own.
- All three accept `div` props. Add `role="status"` and an `aria-label` (e.g. "Loading"), or pair the indicator with visually hidden text.
- For `CircularProgress` with a known `progress`, add `role="progressbar"` with `aria-valuenow`, `aria-valuemin`, and `aria-valuemax`.
- Set `aria-busy` on the region being loaded so assistive tech knows it is updating.
