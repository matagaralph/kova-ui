Tabs let users switch between two or more related panels without changing the URL or leaving their current context. When selecting a tab should change the URL, use links instead.

## Usage
```jsx
import { Tabs } from "kova-ui/components/Tabs";
```

## Best practices

- Use `Tabs` for related panels on the same page that don't change the URL. Use `TabNav` when each tab is a link, and `SegmentedControl` to switch modes of a single view.
- Give each `Tabs.Tab` and `Tabs.Panel` a matching `value` when tabs can be added, removed, or reordered.
- Use `activationMode="manual"` when showing a panel triggers slow or async work.
- Keep labels short, and either give every tab an `icon` or none.
- Use `loadingCounters` while counts load, instead of showing counters one by one.

## Accessibility

- Built on Base UI `Tabs`, with `role="tablist"`, `role="tab"`, and `role="tabpanel"`, and `aria-selected` on the current tab.
- Arrow keys move between tabs. In `"automatic"` mode they also select; in `"manual"` mode `Enter` or `Space` selects.
- Name the tab list with `aria-label`, or `aria-labelledby` when a visible heading describes it.
- Panels stay mounted when hidden, so their state is preserved between tab switches.
