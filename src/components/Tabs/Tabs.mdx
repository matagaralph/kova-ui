Tabs let users switch between two or more related panels without changing the URL or leaving their current context. When selecting a tab should change the URL, use links instead.

## Usage
```jsx
import { Tabs } from "kova-ui/components/Tabs";
```
<Canvas of={TabsStories.Base} additionalActions={[
  { title: 'View story', onClick: linkTo(TabsStories.title, 'Base')}

## More examples

### Selected tab
Select a tab by default with `aria-selected`.

<Canvas of={TabsStories.SelectedTab} />

### Labelled by an external element
Name the tab list with `aria-labelledby` when a visible heading already describes it.

<Canvas of={TabsStories.LabelledByExternalElement} />

### Icons hidden on narrow screens
When the tabs don't fit their container, icons are hidden to save space.

<Canvas of={TabsStories.WithIconsHiddenOnNarrowScreen} />

### Counters in loading state
Use `loadingCounters` while counts are still loading. Every counter shows a loading animation until all are resolved, which prevents repeated layout shifts.

<Canvas of={TabsStories.WithCountersInLoadingState} />

### Controlled
Give each `Tabs.Tab` and `Tabs.Panel` a matching `value`, and keep the selected value in state with `value` and `onChange`. `onChange` fires for every selection method, including arrow keys.

<Canvas of={TabsStories.Controlled} />

### Uncontrolled
Use `defaultValue` to set the initial tab, and let the component manage selection.

<Canvas of={TabsStories.Uncontrolled} />

### Manual activation
With `activationMode="manual"`, arrow keys only move focus; press Enter or Space (or click) to select. Prefer this when switching tabs triggers async work, like a fetch.

<Canvas of={TabsStories.ManualActivation} />

### In an overlay
Tabs manage their own keyboard focus, so they work inside overlays such as a `Popover`.

<Canvas of={TabsStories.InOverlay} />
