<Subtitle>A floating surface for transient content, such as confirmation actions and forms</Subtitle>

Dialogs let people focus on a quick task without leaving the page: confirming an action, disambiguating a choice, or filling in a small form. They appear after a direct interaction, never on page load.

Dialogs are modal. They're dismissed with the close button, the Escape key, clicking the backdrop, or a button in the dialog. Focus is trapped inside while the dialog is open and returns to the trigger when it closes.

## Usage
```jsx
import { Dialog } from "kova-ui/components/Dialog";
```

Render the dialog while it's open, and close it from `onClose`.

### Size variants
- **Small** – for dialogs with very little content.
- **Medium** – for most tasks, such as completing a form or selecting from a list.
- **Large** – for content that needs more horizontal space, such as a comment box.
- **Extra large** (default) – consider whether a new page would be more appropriate.

By default, the height adjusts to the body content. Past the maximum height, the body scrolls.
