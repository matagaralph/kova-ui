Dialogs let people focus on a quick task without leaving the page: confirming an action, disambiguating a choice, or filling in a small form. They appear after a direct interaction, never on page load.

Dialogs are modal. They're dismissed with the close button, the Escape key, clicking the backdrop, or a button in the dialog. Focus is trapped inside while the dialog is open and returns to the trigger when it closes.

## Usage
```jsx
import { Dialog } from "kova-ui/components/Dialog";
```

Render the dialog while it's open, and close it from `onClose`.

### Size variants
- **Small:** for dialogs with very little content.
- **Medium:** for most tasks, like completing a form or picking from a list.
- **Large:** for content that needs more room across, like a comment box.
- **Extra large** (default): before using it, ask whether a new page would work better.

By default, the height adjusts to the body content. Past the maximum height, the body scrolls.

## Best practices

- Open a dialog only in response to a direct action. For non-blocking contextual content, use `Popover`; for longer flows, consider a new page.
- Always set a concise `title`. Add a `subtitle` when the purpose needs one more sentence.
- Keep footer actions to two or three. Use `buttonType="primary"` for the main action and `buttonType="danger"` for destructive ones.
- Use `role="alertdialog"` for confirmations that interrupt the user, such as deleting data.
- Pick the smallest `width` that fits the content, and use `position` to switch to a side or bottom sheet on narrow screens.

## Accessibility

- Built on Base UI Dialog with `modal="trap-focus"`. Focus is trapped inside, and content outside the dialog is hidden from assistive tech.
- The popup sets `role` (`dialog` by default), `aria-modal`, `aria-labelledby` from the title, and `aria-describedby` from the subtitle.
- Escape, a backdrop click, and the close button (labeled "Close") all call `onClose`.
- On open, focus moves to `initialFocusRef`, a footer button with `autoFocus`, or the first focusable element. On close, it returns to the trigger, or to `returnFocusRef` when set.
- With `renderHeader`, put `dialogLabelId` and `dialogDescriptionId` on your title and subtitle so the dialog keeps its accessible name.
