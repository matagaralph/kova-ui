<Subtitle>Vertical navigation between the pages of an app</Subtitle>

NavList renders a vertical list of navigation links, typically in a sidebar. Items can have icons, counts, descriptions, and nested sub-navigation, and can be grouped under headings. The current page is marked with a subtle background and a heavier label.

For horizontal navigation between related views, use [TabNav](?path=/docs/components-tabnav--docs) instead.

## Usage
```jsx
import { NavList } from "kova-ui/components";
```

### Router links
`NavList.Item` works like `TextLink` and `TabNav.Item`. Relative URLs use the link component from `KovaProvider`, external URLs open in a new tab, and `as` overrides the component for a single item. Components that inject `href` into their child, like Next.js `Link` with `legacyBehavior`, also work.

```tsx
import { Link } from "react-router"

// Globally, via KovaProvider
<KovaProvider linkComponent={Link}>
  <NavList aria-label="Workspace">
    <NavList.Item to="/overview" aria-current="page">Overview</NavList.Item>
    <NavList.Item to="/projects">Projects</NavList.Item>
  </NavList>
</KovaProvider>

// Per item, via `as`
<NavList.Item as={Link} to="/settings">Settings</NavList.Item>
```

## Best practices

- Use `NavList` for navigation between pages. Use `Menu` for actions, and `TabNav` for a few related views of the same content.
- Mark exactly one item with `aria-current="page"`.
- Keep labels short, and either give every item a `leadingVisual` or none.
- Keep sub-navigation shallow. If you need more than two levels, consider restructuring the pages.
- Prefer `NavList.Group` titles over custom headings unless the heading needs a link.
- Use `inactiveText` for pages that are temporarily unavailable, rather than hiding them.

## Accessibility

- Renders a `nav` landmark with a list of links. Name it with `NavList.Heading`, `aria-label`, or `aria-labelledby`.
- `aria-current` marks the current item, and is shown with a background and a heavier label, not color alone.
- Items with a `NavList.SubNav` render as buttons with `aria-expanded` and `aria-controls`. The sub-list is labelled by its parent item.
- Group lists are labelled by their heading, and group headings default to one level below `NavList.Heading` (or `h3`).
- Inactive items aren't links. Their warning icon is a focusable button whose tooltip describes why the page is unavailable.
- `NavList.LeadingVisual` is hidden from assistive technology. Trailing visuals are part of the item's name, so add visually hidden text when a count needs context.
