## Examples

### Default inheritance
By default, `TextLink` uses `currentcolor` inheritance and `text-decoration: underline` to create subtle visual differentiation from surrounding text. The hover effect is a dynamic deemphasis of the `currentcolor`, with some special cases for `text-secondary` and `text-tertiary` contexts.

You can see this behavior by changing the text color context of the paragraph the links are in below:

<Canvas of={TextLinkStories.Colors} />

### Primary color
You can create a colorful link style with the `primary` prop, which uses color for visual differentiation.

Primary links also remove the default `underline` treatment - pass `underline` re-apply that style.

<Canvas of={TextLinkStories.Primary} />

### Underline
Links have an underlined aesthetic by default.

Pass `underline={false}` to remove the underline from the link.

<Canvas of={TextLinkStories.Underline} />

### External links
When external paths are provided, `<a>` will be used with `target="_blank"` and `rel="noopener noreferrer"` included by default. You can also compose icons along with the text to add visual indication.

### Font weight
To customize the font weight, pass a Tailwind class to the `className` prop.

## Configure your Router

### Provider

```tsx
// In the root of your App
import {KovaProvider} from "kova-ui/components"
import {Link} from "react-router"

// Set up types 
declare global {
  interface KovaConfig {
    LinkComponent: typeof Link
  }
}

// Wrap your app in KovaProvider and pass in your router's Link component.
export function App() {
  return (
    <KovaProvider linkComponent={Link}>
      {/* other providers... */}
    </KovaProvider>
  )
}

// elsewhere - everything just works!
<TextLink to={{ pathname: "/help" }} prefetch="intent">
  Get Help
</TextLink>
```

### Component-level
You can also pass your Link component to the `as` prop.

```tsx
import {Link} from "next/link"

<TextLink as={Link} href="/dashboard">
  View Dashboard
</TextLink>
```

## Best practices

- Use `TextLink` for navigation inside text. Use `Button` or `ButtonLink` for standalone actions.
- Write link text that makes sense on its own. Avoid "click here".
- Set `linkComponent` on `KovaProvider` once instead of passing `as` to every internal link.
- Keep the default `underline` for links inside paragraphs. Use `primary` or `underline={false}` only where the link is clearly distinct from surrounding text.
- Pair external links with an icon so users know a new tab will open.

## Accessibility

- With `href` or `to`, `TextLink` renders an anchor, or your router's link, with a visible `:focus-visible` ring.
- External URLs open with `target="_blank"` and `rel="noopener noreferrer"`. Mention the new tab in the text or icon label.
- Without `href` or `to`, it renders a `span` with `role="button"` that is not focusable or keyboard-operable. Use `Button` for actions instead.
- The default underline means links are not identified by color alone. Keep it for inline links.
