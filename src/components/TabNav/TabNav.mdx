TabNav displays navigation as a horizontal row of linked tabs. It lets users switch between two or more related views without leaving their current context. If the tabs don't link anywhere, use [Tabs](?path=/docs/components-tabs--docs) instead.

When the items don't fit, the ones that overflow move into a "More" menu, and icons are hidden in narrow containers (see `hideIconsBreakpoint`).

## Usage
```jsx
import { TabNav } from "kova-ui/components/TabNav";
```

### Router links
`TabNav.Item` works like `TextLink` and `ButtonLink`. Relative URLs use the link component from `KovaProvider`, external URLs open in a new tab, and `as` overrides the component for a single item.

```tsx
import { Link } from "react-router"

// Globally, via KovaProvider
<KovaProvider linkComponent={Link}>
  <TabNav aria-label="Workspace">
    <TabNav.Item to="/overview" aria-current="page">Overview</TabNav.Item>
    <TabNav.Item to="/projects">Projects</TabNav.Item>
  </TabNav>
</KovaProvider>

// Per item, via `as`
<TabNav.Item as={Link} to="/settings">Settings</TabNav.Item>
```

## Best practices

- Use `TabNav` when each item links to its own URL. Use `Tabs` for panels on the same page, and `SegmentedControl` for switching modes of one view.
- Mark exactly one item with `aria-current="page"`.
- Keep labels short, and either give every item a `leadingVisual` or none.
- Use `loadingCounters` while counts load, instead of showing counters one by one.
- Use `variant="flush"` when the items should line up with content above and below.

## Accessibility

- Renders a `nav` landmark with a list of links. `aria-label` is required, and missing it throws in development.
- The label is also rendered as a visually hidden heading ("… navigation"), so the navigation appears in heading lists.
- `aria-current` marks the current item. Only one item may be current.
- Overflowing items are hidden from assistive tech and removed from the tab order, and are reachable from the "More" menu. When the current item overflows, the button is announced as "More items, including current item".
