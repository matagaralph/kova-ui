TabNav displays navigation as a horizontal row of linked tabs. It lets users switch between two or more related views without leaving their current context. If the tabs don't link anywhere, use [Tabs](?path=/docs/components-tabs--docs) instead.

When the items don't fit, the ones that overflow move into a "More" menu, and icons are hidden in narrow containers (see `hideIconsBreakpoint`).

## Usage
```jsx
import { TabNav } from "kova-ui/components/TabNav";
```

### Router links
`TabNav.Item` works like `TextLink` and `ButtonLink`. Relative URLs use the link component from `KovaProvider`, external URLs open in a new tab, and `as` overrides the component for a single item.

```tsx
import { Link } from "react-router"

// Globally, via KovaProvider
<KovaProvider linkComponent={Link}>
  <TabNav aria-label="Workspace">
    <TabNav.Item to="/overview" aria-current="page">Overview</TabNav.Item>
    <TabNav.Item to="/projects">Projects</TabNav.Item>
  </TabNav>
</KovaProvider>

// Per item, via `as`
<TabNav.Item as={Link} to="/settings">Settings</TabNav.Item>
```
