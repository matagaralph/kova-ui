## Examples

### Variants
Use the `variant` prop to stylize the select control. Available `variant` styles are similar to `<Button>`, but aligned with subtle differences from `<Input>` variant treatments.

<Canvas of={SelectControlStories.Variants} sourceState="none" />

### Sizing & roundness

Sizing of the control is determined with the `size` prop. Each `size` provides dynamic values for various aspects of the control, including icon and indicator placement, as well `font-size` and gutter values.

Create fully rounded controls with the `pill` prop. When `pill` is set, extra horizontal gutter is dynamically applied, and the clear action is also set to `pill`.

<Canvas of={SelectControlStories.Sizing} sourceState='hidden' />

### Selected

Use `selected` to indicate if the control has a selected value, which toggles visual placeholder styling.

It doesn't change what the control displays. That part is up to you.

<Canvas of={SelectControlStories.Selected} />

### Start icon

Use `StartIcon` to display an icon in the control. Sizing, spacing, and coloring are handled automatically.

<Canvas of={SelectControlStories.StartIcon} />

### Dropdown icon

Use `dropdownIconType` to control the presentation of the dropdown indicator.

<Canvas of={SelectControlStories.DropdownIcon} />

### Clearable

Pass a callback `onClearClick` to enable the clearable action.

<Canvas of={SelectControlStories.Clearable} />

### Loading

During loading, dropdown icon and clear actions are automatically hidden.

Interactions will be prevented by default during this state, by providing a default value for `inert` to `true`. You can override this behavior directly with `inert`, or use `disabled` to add visual disablement.

<Canvas of={SelectControlStories.Loading} />

### Invalid

Use `invalid` to visually indicate the control is in an invalid state.

<Canvas of={SelectControlStories.Invalid} />

### Disabled

Use `disabled` to both visually and accessibly disable the control.

<Canvas of={SelectControlStories.Disabled} />

### Block

Create full-width controls with the `block` prop.

### Optical alignment

Use `opticallyAlign` with either `"start"` or `"end"` to offset the gutter of the control.

## Best practices

- Use `SelectControl` only as a trigger for custom floating UI, like `Menu` or `Popover`. For a standard list of options, use `Select`, which already uses `SelectControl` for its trigger.
- Set `selected` whenever the control shows a real value, so placeholder text stays visually distinct.
- Pass `onClearClick` only when clearing the value is a valid action.
- Use `loading` while options are fetched, rather than `disabled`.
- Match `variant` and `size` to nearby `Input` and `Button` controls.

## Accessibility

- Renders a `span` with `role="button"`. It is focusable when enabled, and uses `aria-disabled` when `disabled` and `aria-busy` while `loading`.
- `Space`, `ArrowDown`, and `ArrowUp` activate the control. `Enter` is ignored, so it can still submit a form.
- The clear action has the accessible name "Clear current value".
- The control does not set `aria-haspopup` or `aria-expanded` itself. Wrap it in a trigger that does, like `Menu.Trigger` or `Popover.Trigger`.
