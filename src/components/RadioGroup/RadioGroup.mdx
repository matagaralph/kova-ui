## Best practices

- Use `RadioGroup` when all options should stay visible and the list is short. Use `Select` for longer lists, and `SegmentedControl` for compact view switches.
- Use `Checkbox` instead when users can pick more than one option.
- Keep option labels short and parallel in structure.
- Use `direction="col"` for longer labels or more than a few options; keep `"row"` for two or three short ones.
- Prefer `disabled` on a single `RadioGroup.Item` over removing it, so users can see the option exists.

## Accessibility

- Built on Radix `RadioGroup`, which renders `role="radiogroup"` with `role="radio"` items and `aria-checked`.
- Arrow keys move focus and selection between items, and only the selected item is in the tab order.
- `aria-label` is required to name the group.
- Each item's children render inside a `label` tied to the radio, so clicking the text selects the option.
