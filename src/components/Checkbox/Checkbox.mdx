## Best practices

- Use `<Checkbox>` for independent options or multi-select lists. Use `<Switch>` for settings that apply immediately and `<RadioGroup>` for mutually exclusive choices.
- Pass `label` to render a clickable label next to the control instead of building your own.
- Use `checked="indeterminate"` for a parent checkbox when only some of its children are selected.
- Use `defaultChecked` for uncontrolled usage, or `checked` with `onCheckedChange` when you manage state.
- Set `name` and `value` when the checkbox is submitted as part of a form.

## Accessibility

- Built on the Radix Checkbox, which renders a `<button role="checkbox">` with `aria-checked`, including `"mixed"` for the indeterminate state.
- Toggles with Space when focused.
- `label` renders a `<label>` linked to the checkbox via `id`, so clicking the label toggles it. Without `label`, associate your own `<label htmlFor>` with the checkbox `id`.
- `disabled` and `required` are passed through to the underlying control.
