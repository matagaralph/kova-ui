FormControl pairs an input with its label, an optional caption, and a validation message. It wires up `id`, `htmlFor`, `aria-describedby`, `disabled`, and `required` for you, so the parts stay connected for assistive technology. It's built on Base UI's `Field`.

## Usage
```jsx
import { FormControl } from "kova-ui/components";
```

<Canvas of={FormControlStories.Base} additionalActions={[
  { title: 'View story', onClick: linkTo(FormControlStories.title, 'Base')}
]} />

FormControl works with `Input`, `Textarea`, `Select`, `TagInput`, `Checkbox`, and `Switch`. Set `id`, `disabled`, and `required` on `FormControl` rather than on the input.

### With a custom input
FormControl can't wire up inputs it doesn't know about. Pass `htmlFor` to `FormControl.Label`, an `id` to `FormControl.Caption` and `FormControl.Validation`, and point the input's `aria-describedby` at those ids yourself.

To connect your own component automatically, read the props with `useFormControlForwardedProps` and spread them onto the input.

## Best practices

- Every input needs a label. Keep it short and use sentence case.
- Use a caption for guidance people need before they type, and a validation message for feedback after.
- Show validation once people have interacted with the field or tried to submit, not while the form is still empty.
- Write error messages that say how to fix the problem, like "Usernames cannot contain spaces".
- Don't put validation on a single checkbox or switch. Show one message for the whole group instead.
- Mark either the required fields or the optional ones, whichever is fewer, and stay consistent within a form.

## Accessibility

- The label is a native `label` linked to the input with `htmlFor`, so clicking it focuses or toggles the input.
- The caption and validation message are linked with `aria-describedby`, so screen readers read them with the input.
- An error validation sets `aria-invalid` on `Input` and `Textarea`.
- A visually hidden label is still read by screen readers.
- With `requiredIndicator={false}`, the required text is hidden from screen readers. The input itself is still marked as required.
- Validation messages are text only. Write them so the meaning is clear without the color.
