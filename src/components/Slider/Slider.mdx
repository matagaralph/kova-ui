## Examples

### Adding a tooltip
A tooltip can easily be added to the Slider label by providing JSX instead of a simple string.
<Canvas of={SliderStories.Tooltips} source={{code: `  <Slider
    label={(
        <Tooltip content="More details about this field">
            <TriggerDecorator>Example field</TriggerDecorator>
        </Tooltip>
    )}
    max={2000}
    min={0}
    onChange={() => {}}
    resetValue={1000}
    step={10}
    unit="ms"
    value={1000}
  />
`}} />

### Marks
Slider marks can be easily added by passing an array of values to the `marks` prop. Responsive behaviors are handled automatically.
<Canvas of={SliderStories.Marks} source={{code: `<Slider
    value={value}
    onChange={() => {}}
    label="Passing grade"
    min={1}
    max={3}
    step={1}
    marks={[
        { value: 1, label: "Inaccurate" },
        { value: 2, label: "Some inaccuracies" },
        { value: 3, label: "Accurate" },
    ]}
    trackColor="#61C454"
    rangeColor="#EF4146"
/>
`}} />

## Best practices

- Use `Slider` when the exact value matters less than its position in a range, like durations or thresholds. For precise numeric entry alone, use `Input`.
- Choose a `step` that matches the precision you need. Decimal steps allow decimal values, and whole-number steps round typed values down.
- Set `unit` or `prefixUnit` so the value is unambiguous.
- Provide `resetValue` when there is a meaningful default to return to.
- Use `marks` for a few named points along the range. Mark values must be unique and within `min` and `max`.

## Accessibility

- The thumb is a Radix `Slider`, with `role="slider"` and keyboard support for arrow keys, `Home`, and `End`.
- The value is also editable in a text input, labelled by `label`. In the input, `ArrowUp` and `ArrowDown` change the value by `step` (`Shift` for 10×), `Home` and `End` jump to the bounds, and `Enter` or `Esc` commits.
- Typed values are clamped to `min` and `max` on blur.
- Always provide a `label`, since it is the only visible name for the control.
