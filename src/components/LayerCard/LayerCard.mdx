## Usage
```jsx
import { LayerCard } from "kova-ui/components/LayerCard";
```

Use `LayerCard.Secondary` for the header row and `LayerCard.Primary` for the main content to get the layered treatment.

### Filter toolbar
Combine `SegmentedControl` and `Input` at `size="xs"` inside a `LayerCard` for compact filter toolbars. Both share the same 26px height.
<Canvas of={LayerCardStories.FilterToolbar} sourceState="none" />

### Custom element
`LayerCard` is built on Base UI's `useRender`, so the `render` prop swaps the root element while keeping its styles. For example, make the whole card a link:

```jsx
<LayerCard render={<a href="/docs/getting-started" />}>
  <LayerCard.Secondary>Getting Started</LayerCard.Secondary>
  <LayerCard.Primary>Quick start guide for new users</LayerCard.Primary>
</LayerCard>
```
