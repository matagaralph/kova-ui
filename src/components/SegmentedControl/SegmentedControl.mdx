### Sizing & roundness
Sizing of the control is controlled with `size` and `gutterSize` props. `size` sets the control to a specific `height`, and `gutterSize` sets the horizontal padding of the inner options.

Each `size` provides default values for `gutterSize`, as well as `font-size` and `border-radius`. Each of these values can be overridden independently.

Create a fully rounded control with the `pill` prop. When `pill` is set, extra horizontal gutter is dynamically applied to the inner options.

<Canvas of={SegmentedControlStories.Sizing} sourceState='hidden' />

### Scrollable
`SegmentedControl` can support scrolling, but is not enabled by default.

To create a scrollable segmented control, wrap the component in a simple `flex` wrapper, which will then cause the control to create inner scrolling when applicable. When scrollable, the selected option will automatically be scrolled into view.

## Best practices

- Use `SegmentedControl` to switch between views or modes of the same content, with two to five options. Use `Tabs` for separate panels of content, and `RadioGroup` for form choices.
- Keep labels to one or two words, and use the same style for every option: all text, all icons, or icon plus text.
- Always keep a value selected. Options cannot be toggled off.
- Use `block` to fill a container, and `pill` only where surrounding controls are also rounded.
- Match `size` to adjacent controls, like `Button` and `Select`.

## Accessibility

- Built on Radix `ToggleGroup` in single mode, so options render as buttons with `role="radio"` and `aria-checked`.
- Arrow keys move focus between options, without wrapping at the ends.
- `aria-label` on `SegmentedControl` is required to name the group.
- Give icon-only options an `aria-label`, because the icon alone has no accessible name.
