<Title>Kova UI</Title>
<Subtitle>Design system for building consistent, high quality apps</Subtitle>

Kova UI is the design system for Amashona, giving every Amashona product a consistent look and feel. It provides styling foundations with Tailwind, CSS variable design tokens, and a library of well-crafted, accessible components. Kova UI includes:

- **Design tokens** for colors, typography, spacing, sizing, shadows, surfaces, and more.
- **Tailwind 4**, pre-configured with Kova UI's design tokens.
- **Component library** of high-quality components, built on Base UI for consistent accessibility.
- **Utilities** for dark mode, responsive layouts, and more.
