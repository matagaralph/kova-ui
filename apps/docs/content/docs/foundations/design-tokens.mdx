Kova's tokens come in three tiers. Use the highest tier that fits:

1. **Component tokens**, like `--switch-track-color-checked`, style one component. Override them to change that component.
2. **Semantic tokens**, like `--color-text-secondary` or `--color-background-danger-soft`, describe a purpose. Use these in your own UI.
3. **Primitives**, like `--gray-500`, are the raw [palettes](/docs/foundations/colors) the others point at.

Tokens with two values switch between light and dark mode. Select a token to copy its `var()`. The tables are generated from Kova's stylesheets, so they always match the installed version.
