Icons are React components, one per icon, from `@kova-ui/icons`. It comes with `kova-ui`, and your bundler keeps only the icons you import.

```tsx
import { Calendar } from "@kova-ui/icons"

<Calendar className="size-4 text-secondary" aria-hidden="true" />
```

Icons draw with `currentColor`, so they take the text color around them. Size them with `size-*` classes or `width` and `height`. Inside Kova components like `Button`, the component sizes them for you.

Icons next to text are decoration: hide them with `aria-hidden="true"`. An icon on its own, like in an icon-only button, needs a name on the control, such as `aria-label`.
