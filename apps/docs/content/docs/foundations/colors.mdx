These are Kova's primitive colors. Components don't use them directly: they read [semantic tokens](/docs/foundations/design-tokens) like `--color-text-secondary`, which point at these. Reach for a primitive only when no semantic token fits.

Grays and alphas flip between light and dark mode, so `--gray-100` is always a subtle step away from the background. The other palettes stay the same in both themes. Select a swatch to copy its `var()`.

## In Tailwind

Every palette is a Tailwind color, like `bg-gray-100`, `text-blue-500` or `border-alpha/10`. Kova replaces Tailwind's default palette, so classes like `bg-slate-100` don't exist.
