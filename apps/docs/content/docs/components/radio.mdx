Use radios for a short list of choices where only one can be picked, like a dialect or a lesson level. The group keeps one value and gives the whole list a single tab stop.

<Preview name="radio/basic" />

Choose Karanga, then use the arrow keys to move the selection between dialects.

## Usage

```tsx
import { Field, Label, Radio } from "kova-ui/components"

function Example() {
  return (
    <Field>
      <Field.Label>Dialect</Field.Label>
      <Radio.Group defaultValue="zezuru">
        <Label>
          <Radio value="zezuru">
            <Radio.Indicator />
          </Radio>
          Zezuru
        </Label>
        <Label>
          <Radio value="karanga">
            <Radio.Indicator />
          </Radio>
          Karanga
        </Label>
      </Radio.Group>
    </Field>
  )
}
```

The field's label names the group. Without a field, name it with `aria-label` or `aria-labelledby`. Without `defaultValue`, nothing starts checked and Tab enters on the first enabled radio. Radios sit in a row by default, and `direction="col"` stacks them.

## Description

Put each radio in its own `Field` with a `Field.Label` and `Field.Description` when an option needs more explanation. That field connects both to its radio, while the outer field still names the group.

<Preview name="radio/description" />

Choose Weekly digest by its label. Each radio is also described by the line under it.

## Choice Card

Wrap an option's content in its label to make the whole card clickable. `has-data-checked:` lets the card reflect the radio inside it.

<Preview name="radio/choice-card" />

Click anywhere on the Record audio card to choose it. Arrow keys move the selection between cards too.

## Fieldset and Legend

Use `Field.Set` and `Field.Legend` to describe a set of choices together. Connect the group to the legend with `aria-labelledby`, and to the description with `aria-describedby`.

<Preview name="radio/legend" />

Choose In Shona. The legend and the line under it describe both options.

## Disabled

Set `disabled` on the group or on one radio. Disabled radios can't be focused or checked, and arrow keys skip them. A disabled fieldset disables the group too, and a disabled group submits nothing.

<Preview name="radio/disabled" />

The Theme group is disabled. In Audio quality, Lossless is disabled, so the arrow keys move between High and Standard.

## Read-Only

Set `readOnly` on the group to keep its value while still letting people focus and read the options. Arrow keys move focus without checking anything, and the value still submits with a form.

<Preview name="radio/read-only" />

Click Editor, or focus Reviewer and press the Down arrow. Reviewer stays checked.

## Controlled

Pass `value` and update it in `onValueChange`. Call `details.cancel()` in the callback to keep the current value. A controller from `createRadioGroupController()` checks a radio from anywhere, like the Publish button below. Create one controller per mounted group.

<Preview name="radio/controlled" />

Choose Draft, then press Publish. The line under the group shows each change and its reason.

## Form

Each radio renders a button with the `radio` role and a hidden native radio, so the group takes part in forms. Set `name` to submit the checked value. The group submits nothing without a name or a checked radio. `required` blocks submission until there's a choice, and a reset returns to `defaultValue`.

Set `form` to a form's id to join it from elsewhere on the page, as this group does.

<Preview name="radio/form" />

Choose Intermediate and press Continue. The submitted value shows under the buttons, and Reset returns the choice to Beginner.

## Validation

Put a required group in a [Field](/docs/components/field) with a `Field.Error`. Submitting without a choice shows the error under the group and moves focus to it.

<Preview name="radio/validation" />

Press Save without a choice to see the error. Choose SMS only and save again.

## Loop

Arrow keys wrap from the last radio to the first. Set `loop` to `false` to stop at the ends.

```tsx
<Radio.Group defaultValue="low" loop={false}>
  ...
</Radio.Group>
```

## Custom Rendering

The group, radio and indicator take `render`. Pass an element and its props merge with the part's, or a function that receives the props and the part's state. Keep the part's props on the interactive element so its role, label and keyboard behavior stay connected.

<Preview name="radio/render" />

Choose Nothing. Each radio renders a full-width button that shows a check from its state.

## API Reference

### Radio.Group

Renders a `<div>` with the `radiogroup` role.

| Prop            | Type                          | Default  | Description                                                       |
| --------------- | ----------------------------- | -------- | ----------------------------------------------------------------- |
| `defaultValue`  | `string \| null`              | `null`   | The radio checked at first, when uncontrolled. A form reset returns to it. |
| `value`         | `string \| null`              |          | The checked radio's value. Pass it to control the group.          |
| `onValueChange` | `(value, details) => void`    |          | Runs when a press, an arrow key, a form reset or a controller changes the value. `details.cancel()` stops it. |
| `direction`     | `"row" \| "col"`              | `"row"`  | Lays the radios out in a row or a column.                         |
| `disabled`      | `boolean`                     | `false`  | Disables every radio and leaves the value out of the form.        |
| `readOnly`      | `boolean`                     | `false`  | Keeps the radios focusable and the value submitted, but stops changes. |
| `required`      | `boolean`                     | `false`  | Blocks form submission until a radio is checked.                  |
| `name`          | `string`                      |          | The name the value submits under.                                 |
| `form`          | `string`                      |          | The id of a form to join from elsewhere on the page.              |
| `loop`          | `boolean`                     | `true`   | Whether arrow keys wrap from the last radio to the first.         |
| `controller`    | `RadioGroupController`        |          | Changes it from outside, from `createRadioGroupController()`.     |

### Radio

Renders a `<button>` with the `radio` role, and a hidden native radio for forms.

| Prop        | Type                          | Default | Description                                         |
| ----------- | ----------------------------- | ------- | --------------------------------------------------- |
| `value`     | `string`                      |         | What the group's value becomes when it's checked.   |
| `disabled`  | `boolean`                     | `false` | Skips the radio, so it can't be focused or checked.    |

### Radio.Indicator

Renders a `<span>` that draws the filled dot while its radio is checked. `keepMounted` keeps it in the page while unchecked. It takes `className` and `render`.

### Data attributes

Every part carries its state as data attributes, like `data-checked` on the checked radio, and a `data-slot`, like `radio-indicator`. Kova styles from them, and so can you. See [data attributes](https://ui-sdk.dev/docs/react/components/radio#data-attributes) for the full list.

Kova adds:

| Attribute        | Values             | Description                        |
| ---------------- | ------------------ | ---------------------------------- |
| `data-direction` | `"row" \| "col"`   | On the group, from `direction`.    |

### CSS variables

| Variable                                       | Default                              |
| ---------------------------------------------- | ------------------------------------ |
| `--radio-group-indicator-size`                 | `--font-text-md-size`                |
| `--radio-group-indicator-background-color`     | `--color-background-primary-solid`, which follows `--kova-primary` |
| `--radio-group-indicator-hole-background-color` | `--color-text-primary-solid`        |
| `--radio-group-indicator-border-color`         | The outline border color             |
| `--radio-group-row-gap`                        | Space between radios in a row        |
| `--radio-group-col-gap`                        | Space between radios in a column     |

## Accessibility

It follows the [WAI-ARIA radio group pattern](https://www.w3.org/WAI/ARIA/apg/patterns/radio/). See the [accessibility reference](https://ui-sdk.dev/docs/react/components/radio#accessibility) for every key and the tested behavior.

- Name the group with a `Field.Label` in a `Field`, or `aria-label`.
- Name each radio with a wrapping `Label`.
