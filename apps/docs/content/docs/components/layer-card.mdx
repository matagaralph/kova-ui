Use a layer card to group a short label with the content it introduces, like a next step on a dashboard or a link to a guide. Without sections, it's a plain card surface.

<Preview name="layer-card/basic" />

## Usage

```tsx
import { LayerCard } from "kova-ui/components"

function Example() {
  return (
    <LayerCard>
      <LayerCard.Secondary>Next steps</LayerCard.Secondary>
      <LayerCard.Primary>Record your first word.</LayerCard.Primary>
    </LayerCard>
  )
}
```

## Surface

Render content directly inside `LayerCard` for a plain card with a border and shadow. Add your own padding.

## Card as a link

`render` swaps any part's element and keeps its styles. Render the card as an `<a>` to make the whole card a link, rather than nesting a link inside. A link card darkens its panel's border on hover and shows a focus ring for the keyboard. The cards on the Introduction page are built this way.

<Preview name="layer-card/link" />

## API Reference

### LayerCard

Renders a `<div>`. It takes every `<div>` attribute.

### LayerCard.Secondary

Renders a `<div>` for a one-line header, behind the primary layer. It takes `render`, `className` and every `<div>` attribute.

### LayerCard.Primary

Renders a `<div>` for the main content, raised above the secondary layer. It takes `render`, `className` and every `<div>` attribute.

### Data attributes

| Attribute      | Present when                         |
| -------------- | ------------------------------------ |
| `data-layered` | The card has sections. On the root.  |

The parts carry the `data-slot` values `layer-card`, `layer-card-secondary` and `layer-card-primary`.

## Accessibility

- The card and its sections are `<div>` elements with no role. Use `render` for a semantic element such as `<section>`, `<article>` or `<a>`.
- A card rendered as a link takes all its text as the link's name. Keep it short, or set `aria-label`.
- Don't put buttons or links inside a card that is itself a link.
- Icon-only buttons in the header need an `aria-label`.
