Use a code block for a snippet of several lines that people read or copy. For a short reference inside a sentence, use an inline `<code>`. [Markdown](/docs/components/markdown) renders its fenced code with a code block.

It ships in `@kova-ui/markdown`, with its highlighter, so apps that don't show code don't load it.

<Preview name="code-block/basic" />

## Installation

```bash
pnpm add @kova-ui/markdown kova-ui
```

```tsx
import { CodeBlock, CodeBlockBase } from "@kova-ui/markdown"
```

## Composition

```text
CodeBlock

CodeBlockBase
├── CodeBlockBase.Code
└── CodeBlockBase.CopyButton
```

`CodeBlock` is a `CodeBlockBase` with its code and copy button. Compose `CodeBlockBase` yourself for your own chrome around the code.

## Usage

```tsx
import { CodeBlock } from "@kova-ui/markdown"

function Example() {
  return <CodeBlock language="bash">pnpm add kova-ui</CodeBlock>
}
```

## Examples

### Languages

`language` picks the grammar. These are registered: `javascript`, `jsx`, `typescript`, `tsx`, `python`, `json`, `jsonc`, `bash`, `markup` (HTML and XML), `css`, `scss`, `sql`, `markdown`, `yaml`, `toml`, `java`, `kotlin`, `go`, `c`, `clike`, `php`, `ruby`, `docker` and `diff`. Any other language shows plain text.

<Preview name="code-block/languages" />

### Custom header

Compose `CodeBlockBase` and `CodeBlockBase.Code` to add your own markup around the code, like a header with the file name and a `CopyButton` from `kova-ui/components`.

## API Reference

### CodeBlock

Renders a `CodeBlockBase` with the highlighted code and a copy button.

| Prop        | Type     | Default | Description                               |
| ----------- | -------- | ------- | ----------------------------------------- |
| `children`  | `string` |         | The code.                                 |
| `language`  | `string` |         | The grammar to highlight it with.         |
| `className` | `string` |         | Classes after Kova's, on the container.   |

### CodeBlockBase

Renders the container `<div>`. It takes every `<div>` attribute.

### CodeBlockBase.Code

Renders a `<pre>` with a `<code>` inside, highlighted with Kova's token colors.

| Prop           | Type                         | Default | Description                                         |
| -------------- | ---------------------------- | ------- | --------------------------------------------------- |
| `children`     | `string`                     |         | The code.                                           |
| `language`     | `string`                     |         | The grammar to highlight it with.                   |
| `codeTagProps` | `HTMLProps<HTMLElement>`     |         | Attributes for the `<code>` element, like `aria-label`. |
| `className`    | `string`                     |         | Classes after Kova's, on the `<pre>`.               |

### CodeBlockBase.CopyButton

Renders a "Copy code" button in the top corner.

| Prop        | Type      | Default | Description                     |
| ----------- | --------- | ------- | ------------------------------- |
| `copyValue` | `string`  |         | The text to copy.               |
| `loading`   | `boolean` | `false` | Shows a loading state.          |
| `disabled`  | `boolean` | `false` | Disables the button.            |
| `className` | `string`  |         | Classes on its container.       |

## Accessibility

| Key             | Does                                           |
| --------------- | ---------------------------------------------- |
| `Tab`           | Moves focus to the copy button.                |
| `Enter`, `Space` | Copies the code.                              |

- Code is in native `<pre>` and `<code>` elements, so screen readers read it as preformatted text.
- The copy button is named "Copy code". A copy button you add yourself needs its own `aria-label`, like "Copy tailwind.config.ts".
- Add an `aria-label` with `codeTagProps` when a snippet needs a description, like its file name.
