Use pagination below a long list or a [DataTable](/docs/components/data-table) to split it into pages. It shows the pages around the current one, with Previous and Next steps, and can show which items the page holds.

<Preview name="pagination/basic" />

## Usage

```tsx
import { Pagination } from "kova-ui/components"

function Example() {
  return (
    <Pagination aria-label="Pagination" pageCount={12}>
      <Pagination.List>
        {({ items }) => (
          <>
            <Pagination.Item>
              <Pagination.Previous />
            </Pagination.Item>
            {items.map((item) => (
              <Pagination.Item key={item}>
                {typeof item === "number" ? <Pagination.Link page={item} /> : <Pagination.Ellipsis />}
              </Pagination.Item>
            ))}
            <Pagination.Item>
              <Pagination.Next />
            </Pagination.Item>
          </>
        )}
      </Pagination.List>
    </Pagination>
  )
}
```

## Range

Pass `total` and `pageSize` instead of `pageCount`, and add `Pagination.Range` to show which items the page holds, like "51‒75 of 243". It announces each change to screen readers. Pass `page` and `onPageChange` to load the rows for the page.

<Preview name="pagination/range" />

## Steps only

`showPages={false}` hides the page links and keeps the steps. By default the links hide below 768px only. Pass `{ narrow, regular, wide }` to choose per viewport, where `wide` is 1400px and up. `Pagination.First` and `Pagination.Last` jump to the ends.

<Preview name="pagination/steps-only" />

## Links

`getHref` turns every page and step into a link, so pages work before JavaScript loads and open in new tabs. Pass your router's link to a part's `render`, like `render={<Link />}`, and read the page from the URL to control it.

## API Reference

### Pagination

Renders a `<nav>` landmark. Name it with `aria-label`.

| Prop           | Type                                              | Default          | Description                                                        |
| -------------- | ------------------------------------------------- | ---------------- | ------------------------------------------------------------------ |
| `pageCount`    | `number`                                          |                  | How many pages there are. Or pass `total` and `pageSize`.          |
| `total`        | `number`                                          |                  | How many items there are.                                          |
| `pageSize`     | `number`                                          | `10`             | How many items fit on a page, with `total`.                        |
| `defaultPage`  | `number`                                          | `1`              | The page it starts on, when uncontrolled.                          |
| `page`         | `number`                                          |                  | The current page, from 1. Pass it to control the pagination.       |
| `onPageChange` | `(page, details) => void`                         |                  | Runs when the page wants to change. `details.cancel()` keeps it.   |
| `siblings`     | `number`                                          | `2`              | How many pages show on each side of the current one.               |
| `boundaries`   | `number`                                          | `1`              | How many pages always show at each end.                            |
| `getHref`      | `(page: number) => string`                        |                  | Makes the pages and steps links to these URLs.                     |
| `showPages`    | `boolean \| { narrow?, regular?, wide? }`         | `{ narrow: false }` | Whether to show the page links, per viewport.                  |
| `controller`   | `PaginationController`                            |                  | Pages it from outside, from `createPaginationController()`.        |

### Pagination.Range

Renders a `<p>` with the items the current page holds, or "Page 3 of 12" without `total`, and a polite live region that announces it.

### Pagination.List

Renders a `<ul>`. Its children can be a function of `{ items, page, pageCount }`.

### Pagination.Item

Renders an `<li>`.

### Pagination.Link

Renders a `<button>`, or an `<a>` with `getHref`.

| Prop        | Type                                              | Description                                     |
| ----------- | ------------------------------------------------- | ----------------------------------------------- |
| `page`      | `number`                                          | The page it goes to, from 1.                    |

### Pagination.Previous, Pagination.Next, Pagination.First, Pagination.Last

Render a `<button>`, or an `<a>` with `getHref`. At the end they go to, they stay focusable and say they're disabled. They take `className`, `render` and `children`.

### Pagination.Ellipsis

Renders a `<span>` with "…", hidden from screen readers.

### Data attributes

Every part carries its state as data attributes, like `data-current` on the current page's link, and a `data-slot`, like `pagination-link`. Kova styles from them, and so can you. See [data attributes](https://ui-sdk.dev/docs/react/components/pagination#data-attributes) for the full list.

Kova adds:

| Attribute         | Values                                            | Description                                                      |
| ----------------- | ------------------------------------------------- | ---------------------------------------------------------------- |
| `data-hide-pages` | `"narrow"`, `"regular"` and `"wide"`, space-separated | On the root: the viewports where page links hide, from `showPages`. |

The current page is filled with `--color-background-primary-solid` and `--color-text-primary-solid`, so it follows `--kova-primary`.

## Accessibility

There's no WAI-ARIA pattern for pagination, so it follows common practice: a `navigation` landmark, a list of buttons or links, and `aria-current="page"` on the current one. See the [accessibility reference](https://ui-sdk.dev/docs/react/components/pagination#accessibility) for every key and the tested behavior.

- Name each pagination with `aria-label`, especially when a page has more than one.
- Links and steps without children are named for screen readers, like "Page 3" and "Previous page".
- `Pagination.Range` announces the items each page holds as it changes.
