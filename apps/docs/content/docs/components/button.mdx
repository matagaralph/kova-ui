Use a button for an action on the current page, like saving an entry or playing a recording. Use [`ButtonLink`](#link-as-button) when it takes people to another page, and [`CopyButton`](#copy-button) to copy text.

<Preview name="button/basic" />

## Usage

```tsx
import { Button } from "kova-ui/components"

function Example() {
  return <Button onClick={() => saveEntry()}>Save entry</Button>
}
```

### Sizes

`size` sets the height, from `3xs` (22px) to `3xl` (48px), with matching gutters, icon and font sizes. `gutterSize` and `iconSize` override them.

### Pill

### With icon

<Preview name="button/with-icon" />

### Icon only

`uniform` makes an icon-only button square, and with `pill`, round. Always name it with `aria-label`, since there's no visible text to read.

<Preview name="button/icon-only" />

### Loading state

`loading` shows a spinner over the label, sets `aria-busy`, and ignores presses while keeping focus. A button whose `onClick` returns a Promise does the same until it settles, and announces "Loading" to screen readers after a second. `inert` ignores presses without changing the look, and defaults to `loading`.

<Preview name="button/loading" />

### Disabled state

`disabled` stops presses, removes the button from the tab order and greys it out. Add `focusableWhenDisabled` to keep it focusable, with `aria-disabled`, so it can explain why it's unavailable. `disabledTone="relaxed"` keeps the default cursor.

<Preview name="button/disabled" />

### Selected

`selected` shows a button as active, like the current section. It only changes styles, so set `aria-pressed` yourself for a toggle. A button that opens a menu or popover looks selected while it's open.

<Preview name="button/selected" />

### Block

`block` fills the available width.

<Preview name="button/block" />

### Optical alignment

`opticallyAlign="start"` or `"end"` pulls a ghost button out by its gutter, so its label lines up with the text around it.

<Preview name="button/optical-alignment" />

### Form

Set `type="submit"` to submit a form and `type="reset"` to reset it. The default, `type="button"`, does neither.

<Preview name="button/form" />

### Link as button

Use `ButtonLink` when the action goes to another page but should look like a button. Internal links use the `linkComponent` from `KovaProvider`, like your router's `Link`. Links starting with `http://` or `https://` open in a new tab; set `external` to decide yourself. Pass `render` to use another link element.

<Preview name="button/link" />

### Disabled link

A disabled `ButtonLink` can't be followed and leaves the tab order.

<Preview name="button/disabled-link" />

### Copy button

`CopyButton` copies `copyValue` when pressed, and swaps its copy icon for a check mark for a moment. Its `children` can be a function of `{ copied }`. Without children it's named "Copy". Pass `aria-label` to say what it copies. The name stays the same while the check mark shows.

## API Reference

### Button

Renders a `<button>`.

| Prop                    | Type                                                                                                | Default     | Description                                                                          |
| ----------------------- | --------------------------------------------------------------------------------------------------- | ----------- | ------------------------------------------------------------------------------------ |
| `variant` | `"primary" \| "secondary" \| "outline" \| "ghost" \| "destructive" \| "secondary-destructive"` | `"primary"` | The button's style. |
| `size`                  | `"3xs" \| "2xs" \| "xs" \| "sm" \| "md" \| "lg" \| "xl" \| "2xl" \| "3xl"`                          | `"md"`      | The height, with matching gutter, icon and font sizes.                               |
| `gutterSize`            | `"3xs" \| "2xs" \| "xs" \| "sm" \| "md" \| "lg" \| "xl"`                                            |             | Overrides the gutter `size` sets.                                                    |
| `iconSize`              | `"sm" \| "md" \| "lg" \| "xl" \| "2xl"`                                                             |             | Overrides the icon size `size` sets.                                                 |
| `pill`                  | `boolean`                                                                                           | `false`     | Rounds the button fully.                                                             |
| `uniform`               | `boolean`                                                                                           | `false`     | Makes it as wide as it is tall, for an icon.                                         |
| `block`                 | `boolean`                                                                                           | `false`     | Fills the available width.                                                           |
| `selected`              | `boolean`                                                                                           | `false`     | Shows the selected style.                                                            |
| `opticallyAlign`        | `"start" \| "end"`                                                                                  |             | Pulls the button out by its gutter on that side.                                     |
| `loading`               | `boolean`                                                                                           | `false`     | Shows a spinner, sets `aria-busy`, and ignores presses while keeping focus.          |
| `inert`                 | `boolean`                                                                                           | `loading`   | Ignores presses and leaves the tab order, without the disabled style.                |
| `disabled`              | `boolean`                                                                                           | `false`     | Stops presses, leaves the tab order, and shows the disabled style.                   |
| `disabledTone`          | `"relaxed"`                                                                                         |             | Keeps the default cursor while disabled.                                             |
| `focusableWhenDisabled` | `boolean`                                                                                           | `false`     | Keeps a disabled button focusable, with `aria-disabled`.                             |
| `type`                  | `"button" \| "submit" \| "reset"`                                                                   | `"button"`  | What it does in a form.                                                              |
| `onClick`               | `(event, details) => unknown`                                                                       |             | Runs on press. Return a Promise to keep the button pending until it settles.         |
| `pendingAnnouncement`   | `string`                                                                                            | `"Loading"` | What screen readers hear once it's been pending for a second.                        |

`children` may also be a function of the state, `{ disabled, pending, error }`.

### ButtonLink

Renders `KovaProvider`'s link component, or an `<a>` for external links. It takes Button's visual props, `disabled`, `className`, `render`, and every anchor prop.

| Prop       | Type      | Default                       | Description                                  |
| ---------- | --------- | ----------------------------- | -------------------------------------------- |
| `href`     | `string`  |                               | Where the link goes.                         |
| `external` | `boolean` | `true` for `http(s)://` links | Opens in a new tab with `rel="noopener noreferrer"`. |

### CopyButton

A Button that copies text. It takes every Button prop.

| Prop        | Type                                                       | Default | Description                                   |
| ----------- | ---------------------------------------------------------- | ------- | --------------------------------------------- |
| `copyValue` | `string \| ClipboardContent \| () => string \| ClipboardContent` |         | What to copy, or a function that returns it.   |
| `children`  | `ReactNode \| ({ copied }) => ReactNode`                   |         | Content after the icon. Without it, the button is named "Copy" unless you pass `aria-label`. |

### Data attributes

The button carries its state as data attributes, like `data-pending` while the Promise `onClick` returned runs, and `data-slot="button"`. Kova styles from them, and so can you. See [data attributes](https://ui-sdk.dev/docs/react/components/button#data-attributes) for the full list. `ButtonLink` is a `Button` rendered as a link, with the same attributes.

Kova adds:

| Attribute              | Values                                                                                                 | Description                                                                                      |
| ---------------------- | ------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------ |
| `data-variant` | `"primary" \| "secondary" \| "outline" \| "ghost" \| "destructive" \| "secondary-destructive"` | Its `variant`. |
| `data-size`            | `"3xs" \| "2xs" \| "xs" \| "sm" \| "md" \| "lg" \| "xl" \| "2xl" \| "3xl"`                             | Its `size`.                                                                                      |
| `data-pill`            |                                                                                                        | `pill` is set.                                                                                   |
| `data-uniform`         |                                                                                                        | `uniform` is set.                                                                                |
| `data-block`           |                                                                                                        | `block` is set.                                                                                  |
| `data-selected`        |                                                                                                        | `selected` is set.                                                                               |
| `data-loading`         |                                                                                                        | `loading` is set.                                                                                |
| `data-inert`           |                                                                                                        | It's inert or loading without being disabled, so it keeps its look. It also has `data-disabled`. |
| `data-optically-align` | `"start" \| "end"`                                                                                     | Its `opticallyAlign`.                                                                            |
| `data-icon-size`       | `"sm" \| "md" \| "lg" \| "xl" \| "2xl"`                                                                | Its `iconSize`.                                                                                  |
| `data-gutter-size`     | `"3xs" \| "2xs" \| "xs" \| "sm" \| "md" \| "lg" \| "xl"`                                               | Its `gutterSize`.                                                                                |
| `data-disabled-tone`   | `"relaxed"`                                                                                            | Its `disabledTone`, while it's disabled.                                                         |

### CSS variables

| Variable              | Default                      |
| --------------------- | ---------------------------- |
| `--button-size`       | The control height of `size` |
| `--button-gutter`     | The gutter of `size`         |
| `--button-icon-size`  | The icon size of `size`      |
| `--button-radius`     | The radius of `size`         |
| `--button-ring-color` | `--color-ring`, or `--color-ring-danger` for destructive variants |

Primary buttons use `--color-background-primary-solid`, which follows `--kova-primary`.

## Accessibility

It renders a native `<button>`. `ButtonLink` renders a native link. See the [accessibility reference](https://ui-sdk.dev/docs/react/components/button#accessibility) for every key and the tested behavior.

- Give every button a visible label, or an `aria-label` when it only has an icon.
- While loading or pending, the button keeps focus and says it's busy. Keep its label the same. The spinner shows progress.
- `selected` only changes styles. Set `aria-pressed` or `aria-expanded` when the button toggles something.
- Use `ButtonLink` for navigation, so people can open it in a new tab and screen readers call it a link.
