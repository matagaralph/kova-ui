---
title: Tag Input
description: Type a list of unique tags, like keywords, labels or email addresses.

Use a tag input when people enter several short values that don't come from a fixed list, like keywords, domains or the email addresses to invite. Each value becomes a tag when they press Enter, type a delimiter, paste a list or leave the field. When the values come from a list of options, use a multiple [Combobox](/docs/components/combobox) instead.

<Preview name="tag-input/basic" />

## Usage

```tsx
import { Field, TagInput } from "kova-ui/components"

function Example() {
  return (
    <Field>
      <Field.Label>Topics</Field.Label>
      <TagInput defaultValue={["design"]}>
        <TagInput.Control>
          <TagInput.Value />
          <TagInput.Input placeholder="Add a topic" />
        </TagInput.Control>
      </TagInput>
    </Field>
  )
}
```

The value is an array of strings. A tag that's already there isn't added again. The existing tag shakes instead.

## Validation

`validator` decides whether a tag is valid. Invalid tags stay in the value and show in red, so people can see and fix them. Paste a list to add several tags at once. It's split on the delimiters and on line breaks.

## Maximum

`maxTags` caps how many tags it accepts. `TagInput.Count` shows the count against it.

## Sizes

`size` on `TagInput.Control` matches the height of an input of the same size for one row, from `md` (32px) to `3xl` (48px), with `xl` (40px) as the default.

<Preview name="tag-input/sizes" />

## Rows and delimiters

`rows` makes the control at least that many rows of tags tall. `delimiters` sets the keys that turn the text into a tag besides Enter. The default is comma and space.

## API Reference

### TagInput

Holds the tags. Renders no element. It takes the [Combobox](/docs/components/combobox#combobox) props for a multiple value, plus these.

| Prop            | Type                              | Default      | Description                                                              |
| --------------- | --------------------------------- | ------------ | ------------------------------------------------------------------------ |
| `defaultValue`  | `string[]`                        |              | The tags at first, when uncontrolled. A form reset returns to them.      |
| `value`         | `string[]`                        |              | The tags. Pass it to control the tag input.                              |
| `onValueChange` | `(value: string[], details) => void` |           | Runs when a tag is added or removed, or a form reset changes the tags. `details.reason` is `input-change` for added tags and `remove-press` for removed ones. |
| `validator`     | `(tag: string) => boolean`        |              | Whether a tag is valid. Invalid tags show in red.                        |
| `delimiters`    | `string[]`                        | `[",", " "]` | Keys that turn the text into a tag, besides Enter. Pasted text is split on them. |
| `maxTags`       | `number`                          |              | How many tags it accepts.                                                |
| `disabled`      | `boolean`                         | `false`      | Stops changes and focus, and leaves it out of the form.                  |
| `readOnly`      | `boolean`                         | `false`      | Keeps the tags submitted, but stops changes.                             |
| `required`      | `boolean`                         | `false`      | Blocks form submission until there's a tag.                              |
| `name`          | `string`                          |              | The name each tag submits under.                                         |
| `controller`    | `TagInputController`              |              | Reads and sets the tags from outside, from `createTagInputController()`. |

### TagInput.Control

Renders a `<div>` with the `toolbar` role. It's the field's frame, holding the tags and the input.

| Prop        | Type                                     | Default | Description                              |
| ----------- | ---------------------------------------- | ------- | ---------------------------------------- |
| `size`      | `"md" \| "lg" \| "xl" \| "2xl" \| "3xl"` | `"xl"`  | The height of a row.                     |
| `rows`      | `number`                                 | `1`     | How many rows tall it is at least.       |

### TagInput.Value

Renders a `TagInput.Tag` for each tag, and no element of its own. Pass a function of the tags as `children` to render them yourself.

### TagInput.Tag

Renders a `<div>` with the `group` role, named by its tag. Without children, it shows the tag's text and a `TagInput.TagRemove` named "Remove" and the tag.

| Prop    | Type     | Default | Description        |
| ------- | -------- | ------- | ------------------ |
| `value` | `string` |         | The tag it shows.  |

### TagInput.TagRemove

Renders a `<button>` that removes its tag, with Kova's close icon when it has no children. Name it with `aria-label`.

### TagInput.Input

Renders the `<input>`. Enter, a delimiter, Tab with text in the field, and leaving the field turn the text into a tag.

### TagInput.Count

Renders a `<div>` with the number of tags, against `maxTags` when it's set, like "2/5".

### Data attributes

TagInput is built on Combobox, with `multiple` set. Its parts carry their state as data attributes, like `data-disabled` on the tags while the tag input is disabled or read-only, and a `data-slot`, like `combobox-chip`. Kova styles from them, and so can you. See [data attributes](https://ui-sdk.dev/docs/react/components/combobox#data-attributes) for the full list. `TagInput.Control` is `ComboboxChips`, `TagInput.Tag` is `ComboboxChip`, `TagInput.TagRemove` is `ComboboxChipRemove` and `TagInput.Input` is `ComboboxInput`.

Kova adds:

| Attribute        | Values                                   | Description                                                      |
| ---------------- | ---------------------------------------- | ---------------------------------------------------------------- |
| `data-size`      | `"md" \| "lg" \| "xl" \| "2xl" \| "3xl"` | On `TagInput.Control`, its `size`.                               |
| `data-invalid`   |                                          | On a tag that `validator` returned false for.                    |
| `data-duplicate` |                                          | On a tag someone just tried to add again. Clears after the shake. |

### CSS variables

| Variable                   | Default        | Description                        |
| -------------------------- | -------------- | ---------------------------------- |
| `--tag-input-rows`         | `1`            | Set by `rows`.                     |
| `--tag-input-height`       | From `size`    | The height of a tag and the input. |
| `--tag-input-tag-spacing`  | From `size`    | The space around and between tags. |
| `--tag-input-font-size`    | From `size`    | The size of the typed text and tags. |

## Accessibility

See the [accessibility reference](https://ui-sdk.dev/docs/react/components/combobox#accessibility) for every key and the tested behavior. The input is a `combobox` that never opens a list, inside a `toolbar` that holds the tags.

- Enter or a delimiter turns the text into a tag, and so does Tab while there's text in the field.
- Name the input with a `Field.Label` or `aria-label`.
- Each tag's remove button is named after its tag, like "Remove design".
- Removed tags are announced, like "design removed".
- Tell people about invalid tags in a `Field.Description` or `Field.Error` too, because red alone doesn't reach everyone.
