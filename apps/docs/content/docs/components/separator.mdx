Use a separator between groups of content that a reader should take as separate, like a profile's header and its bio.

<Preview name="separator/basic" />

Read the profile with a screen reader. It announces a separator between Rudo Mapfumo's name and email and the bio below.

## Usage

Import the separator and put it between two groups of content:

```tsx
import { Separator } from "kova-ui/components"

function Profile() {
  return (
    <section>
      <h2>Rudo Mapfumo</h2>
      <Separator />
      <p>Reviews Karanga entries for the dictionary.</p>
    </section>
  )
}
```

## Vertical

Set `orientation="vertical"` for a line between items in a row. It takes the row's height.

## Decorative

Set `decorative` when the line adds no information. Here, the word “or” already says the two ways to sign in are separate, so a screen reader skips the lines.

<Preview name="separator/decorative" />

Read from Sign in with passkey to Email me a link with a screen reader. It reads “or” and skips the lines.

A decorative separator gets `role="none"` and no `aria-orientation`. It keeps `data-orientation` for styling.

## Custom Rendering

Pass `render` to use a different element, such as `render={<hr />}`. The separator keeps its role, orientation and Kova's styles.

## Styling

The separator draws a 1px line in `--color-border`. A horizontal line takes the full width of its container. A vertical line takes its row's height with `align-self: stretch`, and is at least 16px tall.

In a row next to other content, like the “or” divider above, give each horizontal separator `className="flex-1"` so it fills the space that's left. Change the color or spacing with `className`, and use `data-orientation` to style the two directions apart.

## Data Attributes

The separator carries its orientation as a data attribute, `data-orientation`, and a `data-slot`, `separator`. Kova styles from them, and so can you. See [data attributes](https://ui-sdk.dev/docs/react/components/separator#data-attributes) for the full list.

## API Reference

### Separator

| Prop           | Type                         | Default        | Description                                                                                                                                                                                                         |
| -------------- | ---------------------------- | -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `orientation?` | `"horizontal" \| "vertical"` | `"horizontal"` | Which way the line runs. A vertical separator divides items in a row.                                                                                                                                               |
| `decorative?`  | `boolean`                    | `false`        | Hides the separator from assistive technology with `role="none"`, for a line that's only visual. Leave it off when the separator divides content a screen reader should hear as separate, like groups of menu items. |

### State

| ------------- | ---------------------------- | ----------------------- |

## Accessibility

It follows the [WAI-ARIA separator role](https://www.w3.org/TR/wai-aria-1.2/#separator). See the [accessibility reference](https://ui-sdk.dev/docs/react/components/separator#accessibility) for the tested behavior.

- Set `decorative` only when the surrounding content already conveys the division. A decorative separator gets `role="none"`, so screen readers skip it.

### Tested Behavior

Every line below is an automated test.

- A separator is announced as horizontal by default.
- A vertical separator is announced with its orientation.
- A decorative separator is hidden from assistive technology.
- A separator can't be focused.
- A separator carries its orientation for styling.
