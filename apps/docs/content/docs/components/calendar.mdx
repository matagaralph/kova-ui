Use a calendar when the dates should stay on the page, like in a booking flow or a schedule. For a field that opens a calendar, use a [Date Picker](/docs/components/date-picker).

<Preview name="calendar/basic" />

## Usage

```tsx
import { Calendar } from "kova-ui/components"

function Example() {
  return <Calendar defaultValue="2026-10-16" />
}
```

Dates are ISO strings like `"2026-10-16"`. A single date is a string or `null`, `"multiple"` mode takes a sorted array, and a range is `[start, end]` or `null`.

## Range

`mode="range"` picks a start and then an end, previewing the range in between. The selected ends fill with the primary color, and a band in a tint of it joins them.

<Preview name="calendar/range" />

## Two months

`months={2}` shows two grids side by side. `pageBy="page"` turns both at once.

<Preview name="calendar/two-months" />

## Multiple dates

`mode="multiple"` toggles each date it presses.

<Preview name="calendar/multiple" />

## Min, max and unavailable dates

`min` and `max` stop keys, presses and Previous and Next at the bounds. `unavailable` dates stay focusable, so screen reader users hear them, but can't be picked. They show struck through.

<Preview name="calendar/unavailable" />

## Month and year selects

Write out `Calendar.Header` to put `Calendar.MonthSelect` and `Calendar.YearSelect` between Previous and Next.

## Custom days

Write out the grid to add your own content or classes to each day. `Calendar.Day` takes a function of its state as children.

## Controlled

Pass `value` and `onValueChange` to keep the selection in React, and `month` with `onMonthChange` to control the month shown.

## API Reference

### Calendar

Renders a `<div>`. Without children, it renders the header and one grid per month.

| Prop              | Type                                              | Default    | Description                                                         |
| ----------------- | ------------------------------------------------- | ---------- | ------------------------------------------------------------------- |
| `mode`            | `"single" \| "multiple" \| "range"`               | `"single"` | How many dates it selects.                                          |
| `defaultValue`    | `CalendarValue`                                   |            | The value it starts with.                                           |
| `value`           | `CalendarValue`                                   |            | The selected value. Pass it to control the calendar.                |
| `onValueChange`   | `(value, details) => void`                        |            | Runs when a press or a controller changes the value.                |
| `defaultMonth`    | `string`                                          |            | The first month shown, like `"2026-10"`.                            |
| `month`           | `string`                                          |            | The first month shown. Pass it with `onMonthChange` to control it.  |
| `min`             | `string`                                          |            | The earliest date that can be picked.                               |
| `max`             | `string`                                          |            | The latest date that can be picked.                                 |
| `unavailable`     | `DateMatchers`                                    |            | Dates that can't be picked.                                         |
| `minDays`         | `number`                                          |            | The fewest days a range can span.                                   |
| `maxDays`         | `number`                                          |            | The most days a range can span.                                     |
| `months`          | `number`                                          | `1`        | How many months show side by side.                                  |
| `pageBy`          | `"month" \| "page"`                               | `"month"`  | Whether Previous and Next turn one month or all of them.            |
| `showOutsideDays` | `boolean`                                         | `false`    | Whether days of the months before and after fill the edges.         |
| `fixedWeeks`      | `boolean`                                         |            | Whether every month shows six weeks.                                |
| `weekStartsOn`    | `number`                                          |            | The first day of the week, 0 for Sunday. Defaults to the locale's.  |
| `locale`          | `string`                                          |            | The language of names and labels. Defaults to the page's `lang`.    |
| `today`           | `string`                                          |            | Today's date, for the today marker.                                 |
| `deselectable`    | `boolean`                                         | `false`    | Whether pressing the selected date again clears it.                 |
| `disabled`        | `boolean`                                         | `false`    | Stops focus and selection.                                          |
| `readOnly`        | `boolean`                                         | `false`    | Allows focus and navigation, but not selection.                     |
| `controller`      | `CalendarController`                              |            | Drives it from outside, from `createCalendarController()`.          |

### Calendar.Header

Renders a `<div>` that lays out its children in a row. Without children, it renders `Calendar.Previous`, `Calendar.Heading` and `Calendar.Next`.

### Calendar.Previous and Calendar.Next

Render `<button>`s named "Previous month" and "Next month", with chevron icons when they have no children. They're disabled at `min` and `max`.

### Calendar.Heading

Renders an `<h2>` naming the months shown, like "October 2026". The grids are labelled by it.

### Calendar.MonthSelect and Calendar.YearSelect

Render native `<select>`s that change the first month shown. Name them with `aria-label`.

### Calendar.Months

Renders a `<div>` that lays grids side by side. It takes `months`, and renders one `Calendar.Grid` per month when it has no children.

### Calendar.Grid

Renders a `<table>` with the `grid` role, named by its month. `offset` says which of the months shown it is, from 0. Without children, it renders the weekday headers and days.

### Calendar.Weekdays, Calendar.Weekday, Calendar.Weeks and Calendar.Day

`Calendar.Weekdays` renders the header row and calls its children with each column's index. Render a `Calendar.Weekday` with that `index`. `Calendar.Weeks` renders the week rows and calls its children with each cell. Render a `Calendar.Day` with `value={cell.date}`. A day is a focusable `<td>` with the `gridcell` role, named by its full date.

### Data attributes

Every part carries its state as data attributes, like `data-selected` on a selected day, and a `data-slot`, like `calendar-day`. Kova styles from them, and so can you. See [data attributes](https://ui-sdk.dev/docs/react/components/calendar#data-attributes) for the full list.

### CSS variables

| Variable                             | Default                                                   |
| ------------------------------------ | --------------------------------------------------------- |
| `--calendar-cell-size`               | `30px`                                                    |
| `--calendar-cell-gutter`             | `2px`                                                     |
| `--calendar-day-selected-background` | `--color-background-primary-solid`, from `--kova-primary` |
| `--calendar-day-selected-color`      | `--color-text-primary-solid`                              |
| `--calendar-range-background`        | The primary color at 8%                                   |

## Accessibility

See the [accessibility reference](https://ui-sdk.dev/docs/react/components/calendar#accessibility) for every key and the tested behavior.

- Previous and Next are named in English. Pass `aria-label` to translate them.
- Explain why dates are unavailable in text near the calendar, because the strike-through alone doesn't say why.
