Use an alert for a message that stays in place until it no longer applies, like scheduled maintenance, an entry that needs changes or a recording that failed to upload. For a short status label, use a [Badge](/docs/components/badge).

<Preview name="alert/basic" />

## Usage

```tsx
import { Alert } from "kova-ui/components"

function Example() {
  return (
    <Alert
      title="Scheduled maintenance"
      description="The dictionary will be read-only 2–4 AM CAT on July 14."
    />
  )
}
```

## Colors and variants

`color` matches the alert to the intent of its message, and `variant` sets how strongly it stands out, with `outline` (the default) or `soft`. `outline` draws a colored border and icon, and `soft` a light tint with a tinted border and a colored icon. The icon sits at the top, beside the title. The `primary` color follows your brand color.

<Preview name="alert/colors" />

## Title or description only

Both `title` and `description` are optional. A description can hold links and other inline content.

<Preview name="alert/title" />

## Actions

`actions` takes buttons or links for the message, like a way to dismiss it or to fix the problem.

<Preview name="alert/actions" />

## Actions placement

Actions sit at the end of the alert, and move under the message when they take more than a third of its width. Set `actionsPlacement` to `"end"` or `"bottom"` to fix their place, for example for a long message with two actions.

<Preview name="alert/actions-placement" />

## Indicator

The icon follows `color`. It's a check for `success`, a warning sign for `danger`, `warning` and `caution`, and an info icon otherwise. Pass an icon to `indicator` to replace it, or `false` to hide it.

## API Reference

### Alert

Renders a `<div>`, with `role="alert"` when `color` is `"danger"`. It also takes every `<div>` attribute except `title` and `color`, which it uses for its own props.

| Prop               | Type                                                                                       | Default     | Description                                                                 |
| ------------------ | ------------------------------------------------------------------------------------------ | ----------- | --------------------------------------------------------------------------- |
| `title`            | `ReactNode`                                                                                |             | The short title of the message.                                             |
| `description`      | `ReactNode`                                                                                |             | Supporting text under the title.                                            |
| `actions`          | `ReactNode`                                                                                |             | Buttons or links for the message.                                           |
| `actionsPlacement` | `"end" \| "bottom"`                                                                        |             | Fixes where actions go. Without it, they wrap when wider than a third of the alert. |
| `color`            | `"primary" \| "success" \| "danger" \| "warning" \| "caution" \| "info" \| "discovery"`    | `"primary"` | The intent of the message.                                                  |
| `variant`          | `"outline" \| "soft"`                                                           | `"outline"` | How strongly the alert stands out.                                          |
| `indicator`        | `ReactNode \| false`                                                                       |             | Replaces the icon chosen from `color`. `false` hides it.                    |
| `actionsClassName` | `string`                                                                                   |             | Classes on the actions container.                                           |
| `ref`              | `Ref<HTMLDivElement>`                                                                      |             | The alert element.                                                          |

### Data attributes

| Attribute                 | Value                                    |
| ------------------------- | ---------------------------------------- |
| `data-color`              | The `color` prop.                        |
| `data-variant`            | The `variant` prop.                      |
| `data-actions-placement`  | `"end"` or `"bottom"`, set or measured.  |

The alert has `data-slot="alert"`, and its parts `alert-indicator`, `alert-title`, `alert-description` and `alert-actions`.

### CSS variables

| Variable                    | Default                                          |
| --------------------------- | ------------------------------------------------ |
| `--alert-gutter`            | `spacing(4)`, the padding                        |
| `--alert-gap`               | `spacing(3)`, between the icon and the message   |
| `--alert-border-radius`     | `--radius-xl`                                    |
| `--alert-font-size`         | `--font-text-sm-size`                            |
| `--alert-line-height`       | `--font-text-sm-line-height`                     |
| `--alert-title-font-weight` | `--font-weight-semibold`                         |
| `--alert-indicator-size`    | `20px`                                           |
| `--alert-tint`              | The `soft` background, from `color`              |
| `--alert-tint-border`       | The `soft` border, from `color`                  |
| `--alert-accent`            | The icon color in `outline` and `soft`           |
| `--alert-outline`           | The `outline` border, from `color`               |

## Accessibility

- An alert with `color="danger"` has `role="alert"`, so screen readers announce it when it appears. Other colors are read in place, with no announcement. Render a danger alert only when there's something to announce, not on page load.
- The icon is decorative. The title or description has to carry the message without its color or icon.
- Use labeled buttons in `actions`, like "Dismiss" rather than a lone close icon, so they have clear names for keyboard and screen reader users.
