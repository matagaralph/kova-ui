---
title: Delete Resource
description: Confirm a permanent delete by typing the resource's name.
---

Use Delete Resource before deleting something that can't be restored, like a project, a workspace or an API key. The person types the resource's name to enable the delete button, which makes deleting the wrong thing by habit or by accident much less likely. It's an [Alert Dialog](/docs/components/alert-dialog) with Kova's layout, a copy button for the name and a confirmation field.

<Preview name="delete-resource/basic" />

## Usage

```tsx
import { AlertDialog, Button, DeleteResource } from "kova-ui/components"

function Example() {
  return (
    <DeleteResource resourceType="Project" resourceName="apollo-web" onDelete={deleteProject}>
      <AlertDialog.Trigger render={<Button color="danger" />}>Delete project</AlertDialog.Trigger>
    </DeleteResource>
  )
}
```

## Controlled

Pass `open` and `onOpenChange` to open it from anywhere, like a menu item. A synchronous `onDelete` closes the dialog right away.

<Preview name="delete-resource/controlled" />

## Errors and options

When `onDelete` returns a Promise, the dialog stays open and the delete button shows a loading state until it settles. It closes when the Promise resolves. When it rejects, it stays open so `errorMessage` can say what went wrong. `caseSensitive={false}` accepts the name in any case, `deleteButtonText` relabels the delete button, and `size="sm"` makes the dialog narrower.

<Preview name="delete-resource/error" />

If you track the delete yourself, pass `isDeleting` while it runs. It disables the field and both buttons, and keeps Escape from closing the dialog.

## API Reference

### DeleteResource

Renders an `AlertDialog` with its backdrop and content.

| Prop               | Type                                 | Default  | Description                                                                                                |
| ------------------ | ------------------------------------ | -------- | ---------------------------------------------------------------------------------------------------------- |
| `resourceType`     | `string`                             |          | The kind of resource, like `"Project"`. Required.                                                          |
| `resourceName`     | `string`                             |          | The resource's name, which the person types to confirm. Required.                                          |
| `onDelete`         | `() => unknown`                      |          | Runs when the person confirms. Return a Promise to keep the dialog open and pending until it settles. Required. |
| `open`             | `boolean`                            |          | Whether it's open. Pass it to control the dialog.                                                          |
| `defaultOpen`      | `boolean`                            | `false`  | Whether it starts open, when uncontrolled.                                                                 |
| `onOpenChange`     | `(open: boolean, details) => void`   |          | Runs when it wants to open or close. After a delete, `details.returnValue` is `"confirm"`.                 |
| `onOpenChangeComplete` | `(open: boolean) => void`        |          | Runs once opening or closing has finished, after the animation.                                            |
| `controller`       | `AlertDialogController`              |          | Opens and closes it from anywhere, from `createAlertDialogController()`.                                   |
| `isDeleting`       | `boolean`                            | `false`  | Locks the dialog while a delete you track yourself runs.                                                   |
| `caseSensitive`    | `boolean`                            | `true`   | Whether the typed name must match the case of `resourceName`.                                              |
| `deleteButtonText` | `string`                             | `"Delete {resourceType}"` | The delete button's text.                                                                 |
| `errorMessage`     | `string`                             |          | Shown in a danger alert above the description.                                                             |
| `size`             | `"sm" \| "base"`                     | `"base"` | The dialog's width, 296px or 384px.                                                                        |
| `children`         | `ReactNode`                          |          | Rendered inside the alert dialog's root, like an `AlertDialog.Trigger`.                                     |

### Data attributes

The content has `data-component="DeleteResource"`, plus the alert dialog's own attributes. `data-open`, `data-starting-style` and `data-ending-style` are on the content and backdrop, and `data-pending` is on the delete button while `onDelete` runs.

## Accessibility

The dialog has the `alertdialog` role, named `Delete {resourceName}` and described by its warning. It follows the [WAI-ARIA alert dialog pattern](https://www.w3.org/WAI/ARIA/apg/patterns/alertdialog/).

| Key                | Does                                                                       |
| ------------------ | -------------------------------------------------------------------------- |
| `Tab`, `Shift+Tab` | Moves between the copy button, the field, Cancel and Delete.               |
| `Enter`, `Space`   | Presses the focused button. Delete does nothing until the name matches.    |
| `Escape`           | Closes the dialog, unless a delete is running.                             |

- Focus starts in the confirmation field, which is labeled `Type {resourceName} to confirm deletion`.
- The copy button is labeled `Copy {resourceName} to clipboard`.
- While a delete runs, screen readers hear "Loading" after a second.
