---
title: Circular Progress
description: Show a task's progress in a small ring.
---

Use circular progress for a task that will finish, like an upload, where a bar doesn't fit. Pass `value` when you know how far the task has come. Without it, the ring fills on a timer that slows as it nears the end, until you set `done`. For a wait with no progress at all, use a [Loading Indicator](/docs/components/loading-indicator).

<Preview name="circular-progress/basic" />

## Usage

```tsx
import { CircularProgress } from "kova-ui/components"

function Example() {
  return <CircularProgress aria-label="Uploading report.pdf" value={60} />
}
```

## Simulated progress

Leave out `value` when the task can't report progress. The ring fills quickly at first and slows as it nears the end over `maxDuration` milliseconds, without ever finishing on its own. Set `done` when the task ends to fill it. Screen readers hear an indeterminate progress bar until then, since the fill isn't real.

<Preview name="circular-progress/simulated" />

## Changing the value

Pass the latest `value` as the task goes. `min` and `max` default to 0 and 100. Here `max` is the number of photos.

<Preview name="circular-progress/controlled" />

## Size and stroke

`size` sets the width and height, 28px by default, and `strokeWidth` the ring's width, from 1 to 4 pixels.

<Preview name="circular-progress/sizes" />

## Colors

The filled ring uses your brand color (`--kova-primary`), or green without one. `trackActiveColor` and `trackColor` set the filled and unfilled colors.

## API Reference

### CircularProgress

Renders a `<div>` with the `progressbar` role and two `<svg>` rings.

| Prop               | Type                             | Default  | Description                                                                 |
| ------------------ | -------------------------------- | -------- | --------------------------------------------------------------------------- |
| `value`            | `number`                         |          | How far the task has come, between `min` and `max`. Leave it out to simulate progress. |
| `done`             | `boolean`                        | `false`  | Ends simulated progress and fills the ring.                                 |
| `maxDuration`      | `number`                         | `15000`  | How long simulated progress takes to near the end, in milliseconds.         |
| `min`              | `number`                         | `0`      | The lowest value.                                                           |
| `max`              | `number`                         | `100`    | The highest value.                                                          |
| `format`           | `Intl.NumberFormatOptions \| (value) => string` | Percent | How screen readers read the value.                         |
| `getValueLabel`    | `(value, details) => string`     |          | The text screen readers hear for the value, like "3 of 5 photos".           |
| `size`             | `number \| string`               | `28`     | Width and height. A number is in pixels.                                    |
| `strokeWidth`      | `number`                         | `2`      | Width of the ring, in pixels, up to 4.                                      |
| `trackActiveColor` | `string`                         |          | Color of the filled ring.                                                   |
| `trackColor`       | `string`                         |          | Color of the unfilled ring.                                                 |
| `style`            | `CSSProperties \| (state) => CSSProperties` |  | Styles merged over the variables the props set.                  |

### Data attributes

The root carries its state as data attributes, like `data-complete` once the value reaches `max` or `done` is set, and `data-slot="progress"`. Kova styles from them, and so can you. See [data attributes](https://ui-sdk.dev/docs/react/components/progress#data-attributes) for the full list and the CSS variable `--progress-value`. `CircularProgress` is the `Progress` root, drawn as a ring.

### CSS variables

| Variable                                 | Default                    |
| ---------------------------------------- | -------------------------- |
| `--circular-progress-size`               | `28px`                     |
| `--circular-progress-stroke`             | `2px`                      |
| `--circular-progress-track-active-color` | `--kova-primary`, or green |
| `--circular-progress-track-color`        | Light green                |

## Accessibility

It follows the [WAI-ARIA `progressbar` role](https://www.w3.org/TR/wai-aria-1.2/#progressbar). It isn't focusable and has no keyboard interaction. See the [accessibility reference](https://ui-sdk.dev/docs/react/components/progress#accessibility) for the tested behavior.

- Name it with `aria-label` or `aria-labelledby`, like "Uploading report.pdf".
- Use `getValueLabel` when a percentage says too little, like "3 of 5 photos".
- Simulated progress reads as indeterminate, so screen readers never hear made-up numbers.
