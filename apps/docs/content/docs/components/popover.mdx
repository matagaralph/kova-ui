---
title: Popover
description: Show content or a small task beside its trigger.
---

Use a popover for content tied to a control that the person may interact with, like a quick rename form, a filter panel or a profile card. It doesn't block the page, and pressing outside or moving focus away closes it. For a task that needs full attention, use a [Dialog](/docs/components/dialog). For a short read-only hint, use a [Tooltip](/docs/components/tooltip).

<Preview name="popover/basic" />

## Usage

```tsx
import { Button, Popover } from "kova-ui/components"

function Example() {
  return (
    <Popover>
      <Popover.Trigger render={<Button variant="outline" />}>Details</Popover.Trigger>
      <Popover.Content className="p-4">
        <Popover.Title>Last updated today</Popover.Title>
      </Popover.Content>
    </Popover>
  )
}
```

## Form

Focus moves to the first field when the popover opens. `Popover.Close` closes it and returns focus to the trigger.

<Preview name="popover/form" />

## Placement

`side` chooses the side of the trigger and `align` lines the popover up with its start, center or end. The popover flips or shifts when there isn't room. `sideOffset` (8px by default) sets the gap. When aligned to the start or end, it shifts out by 5px so its content lines up with the trigger's. `alignOffset` changes that.

<Preview name="popover/placement" />

## Open on hover

`openOnHover` opens the popover when the pointer rests on the trigger for `delay` milliseconds. Pressing the trigger still opens it, so keyboard and touch users can reach it too.

<Preview name="popover/hover" />

## Size and surface

The popover is at least 300px wide and at most 700px, never wider than the space beside the trigger. `width`, `minWidth` and `maxWidth` change that. `translucent` blurs the page behind a see-through surface.

<Preview name="popover/size" />

## Controlled

Pass `open` and update it in `onOpenChange`. `details.reason` says why it opened or closed, like `trigger-press`, `outside-press` or `escape-key`.

## API Reference

### Popover

Shares state between the parts. Renders no element.

| Prop           | Type                                | Default | Description                                                                                     |
| -------------- | ----------------------------------- | ------- | ----------------------------------------------------------------------------------------------- |
| `defaultOpen`  | `boolean`                           | `false` | Whether it starts open, when uncontrolled.                                                      |
| `open`         | `boolean`                           |         | Whether it's open. Pass it to control the popover.                                              |
| `onOpenChange` | `(open: boolean, details) => void`  |         | Runs when it wants to open or close. `details.reason` says why and `details.cancel()` stops it.   |
| `modal`        | `boolean \| "trap-focus"`           | `false` | `false` leaves the page usable and closes when focus leaves. `true` traps focus and makes the page inert. |
| `openOnHover`  | `boolean`                           | `false` | Opens when the pointer rests on the trigger.                                                    |
| `delay`        | `number`                            |         | Milliseconds before it opens on hover.                                                          |
| `closeDelay`   | `number`                            |         | Milliseconds before it closes once the pointer leaves, with `openOnHover`.                      |
| `dismissible`  | `boolean`                           | `true`  | Whether Escape, an outside press and focus leaving can close it.                                |
| `presentation` | `"popover" \| "sheet" \| "auto"`    | `"popover"` | `"auto"` presents it as a sheet on small touch screens.                                     |
| `controller`   | `PopoverController`                 |         | Opens and closes it from anywhere, from `createPopoverController()`.                            |

### Popover.Trigger

Renders a `<button>` that toggles the popover. Use `render={<Button />}` for Kova's button styles. Takes `disabled`, `payload`, `shortcut` and `render`.

### Popover.Content

Renders the popover, a `<div>` with the `dialog` role in the browser's top layer.

| Prop               | Type                                               | Default    | Description                                                          |
| ------------------ | -------------------------------------------------- | ---------- | -------------------------------------------------------------------- |
| `side`             | `"top" \| "right" \| "bottom" \| "left"`           | `"bottom"` | The side of the trigger it opens on.                                 |
| `align`            | `"start" \| "center" \| "end"`                     | `"center"` | How it lines up with the trigger.                                    |
| `sideOffset`       | `number`                                           | `8`        | The gap to the trigger, in pixels.                                   |
| `alignOffset`      | `number`                                           | `-5`       | The shift along the trigger, in pixels, for `start` and `end`.       |
| `collisionPadding` | `number`                                           | `20`       | Space kept from the window's edges.                                  |
| `anchor`           | `string \| Element \| { x, y } \| null`            |            | Positions it against this instead of the trigger.                    |
| `width`            | `number \| "auto"`                                 | `"auto"`   | The width, in pixels.                                                |
| `minWidth`         | `number \| "auto"`                                 | `300`      | The minimum width, in pixels.                                        |
| `maxWidth`         | `number`                                           | `700`      | The maximum width, in pixels.                                        |
| `translucent`      | `boolean`                                          | `false`    | Blurs the page behind a see-through surface.                         |
| `initialFocus`     | `"auto" \| "content" \| "none" \| string \| HTMLElement \| () => HTMLElement` | `"auto"` | Where focus goes when it opens. |
| `finalFocus`       | `"trigger" \| "none" \| string \| HTMLElement \| () => HTMLElement` | `"trigger"` | Where focus goes when it closes.          |

### Popover.Title

Renders an `<h2>` that names the popover.

### Popover.Description

Renders a `<p>` that describes the popover.

### Popover.Close

Renders a `<button>` that closes the popover. Use `render={<Button />}` for Kova's button styles.

### Data attributes

Every part carries its state as data attributes, like `data-open` on the trigger and content while the popover is open, and a `data-slot`, like `popover-content`. Kova styles from them, and so can you. See [data attributes](https://ui-sdk.dev/docs/react/components/popover#data-attributes) for the full list and the CSS variables, like `--transform-origin`.

Kova adds:

| Attribute          | Values | Description                                    |
| ------------------ | ------ | ---------------------------------------------- |
| `data-translucent` |        | On the content, when `translucent` is set.     |

### CSS variables

| Variable               | Default                                       |
| ---------------------- | --------------------------------------------- |
| `--popover-radius`     | `--radius-xl`                                 |
| `--popover-width`      | Set from `width`                              |
| `--popover-min-width`  | Set from `minWidth`, `300px` without it       |
| `--popover-max-width`  | Set from `maxWidth`, `700px` without it       |

## Accessibility

See the [accessibility reference](https://ui-sdk.dev/docs/react/components/popover#accessibility) for every key and the tested behavior.

- Give every popover a `Popover.Title`, or an `aria-label` on the content.
- Name icon-only triggers with `aria-label`.
- Keep popovers out of clickable cards and links, because clicks inside them bubble to the elements around them.
