---
title: Tabs
description: Switch between related panels with one tab selected at a time.
---

Use tabs when several views of the same thing share one space, like a word's meaning, recordings and history. Selecting a tab shows its panel without changing the URL. When each tab is its own page, use [TabNav](/docs/components/tab-nav) instead, and use a [Segmented Control](/docs/components/segmented-control) to switch modes of a single view.

<Preview name="tabs/basic" />

## Usage

```tsx
import { Tabs } from "kova-ui/components"

function Example() {
  return (
    <Tabs defaultValue="meaning">
      <Tabs.List aria-label="Word">
        <Tabs.Tab value="meaning">Meaning</Tabs.Tab>
        <Tabs.Tab value="recordings">Recordings</Tabs.Tab>
        <Tabs.Indicator />
      </Tabs.List>
      <Tabs.Panel value="meaning">mvura, noun. Water.</Tabs.Panel>
      <Tabs.Panel value="recordings">Tendai Moyo recorded it in Zezuru.</Tabs.Panel>
    </Tabs>
  )
}
```

## Counters

`counter` shows a count in a badge after the label, like the number of entries waiting for review. It takes a number or a string, like `"1.2K"`, and screen readers hear it in parentheses after the label.

<Preview name="tabs/counters" />

## Loading counters

Set `loadingCounters` on `Tabs` while the counts load. Every counter shows loading dots until you turn it off, so the tabs shift once instead of once per counter.

<Preview name="tabs/loading-counters" />

## Icons

Put an icon in a `Tabs.TabIcon`. It sits before the label, stays out of the tab's name, and hides when the list gets too narrow to show every tab with its icon. Give every tab an icon, or none.

<Preview name="tabs/icons" />

## Disabled

`disabled` stops a tab from being selected. Arrow keys still reach it, so people can find it.

<Preview name="tabs/disabled" />

## Controlled

Pass `value` and `onValueChange` to keep the selected tab in React. `onValueChange` runs for clicks and arrow keys, with a `details.reason`.

<Preview name="tabs/controlled" />

## Manual activation

With `activation="manual"`, arrow keys only move focus, and Enter or Space selects. Use it when showing a panel is slow, like a panel that fetches data.

<Preview name="tabs/manual" />

## Vertical

`orientation="vertical"` stacks the tabs beside their panels, with Up and Down Arrow moving between them.

<Preview name="tabs/vertical" />

## Links

Render a tab as a link with `render`, like `render={<a href="#recordings" />}`. It keeps its tab role. When every tab is a page of its own, use [TabNav](/docs/components/tab-nav).

## API Reference

### Tabs

Renders a `<div>` around the list and panels.

| Prop               | Type                                    | Default        | Description                                                              |
| ------------------ | --------------------------------------- | -------------- | ------------------------------------------------------------------------ |
| `defaultValue`     | `string \| null`                        | First enabled  | The tab selected at first, when uncontrolled.                            |
| `value`            | `string \| null`                        |                | The selected tab. Pass it to control the tabs.                           |
| `onValueChange`    | `(value, details) => void`              |                | Runs when the selection wants to change. `details.cancel()` stops it.    |
| `activation`       | `"automatic" \| "manual"`               | `"automatic"`  | Whether arrow keys select, or only move focus.                           |
| `orientation`      | `"horizontal" \| "vertical"`            | `"horizontal"` | Which arrow keys move between tabs, and how the list lays out.           |
| `loop`             | `boolean`                               | `true`         | Whether arrow keys wrap from the last tab to the first.                  |
| `hiddenUntilFound` | `boolean`                               | `false`        | Keeps hidden panels findable with the browser's find in page.            |
| `loadingCounters`  | `boolean`                               | `false`        | Shows loading dots in every counter until all counts are ready.          |
| `controller`       | `TabsController`                        |                | Selects tabs from outside, from `createTabsController()`.                |

### Tabs.List

Renders the `tablist`, a scrolling row with a bottom border. Name it with `aria-label` or `aria-labelledby`.

### Tabs.Tab

Renders a `<button>` with the `tab` role.

| Prop        | Type                                              | Default | Description                                         |
| ----------- | ------------------------------------------------- | ------- | --------------------------------------------------- |
| `value`     | `string`                                          |         | Pairs the tab with the panel of the same value.     |
| `disabled`  | `boolean`                                         | `false` | Keeps it focusable, but stops it being selected.    |
| `counter`   | `number \| string`                                |         | A count shown in a badge after the label.           |

### Tabs.TabIcon

Renders a `<span>` for a decorative icon before the label. `mirror` flips a directional icon in right-to-left text.

### Tabs.Indicator

Renders a `<span>` that underlines the selected tab, measured from the list. It takes `className` and `render`.

### Tabs.Panel

Renders a `<div>` with the `tabpanel` role, labelled by its tab.

| Prop               | Type      | Default | Description                                              |
| ------------------ | --------- | ------- | -------------------------------------------------------- |
| `value`            | `string`  |         | The value of the tab it belongs to.                      |
| `keepMounted`      | `boolean` | `false` | Keeps it in the page, hidden, to preserve its state.     |
| `hiddenUntilFound` | `boolean` | `false` | Keeps it findable with find in page while hidden.        |

### Data attributes

Every part carries its state as data attributes, like `data-selected` on the selected tab and its panel, and a `data-slot`, like `tabs-tab`. Kova styles from them, and so can you. See [data attributes](https://ui-sdk.dev/docs/react/components/tabs#data-attributes) for the full list and the CSS variables, like `--active-tab-width`.

Kova adds:

| Attribute           | Values | Description                                               |
| ------------------- | ------ | --------------------------------------------------------- |
| `data-icons-hidden` |        | On `Tabs.List`, while it's too narrow, so icons are hidden. |

### CSS variables

| Variable                 | On        | Default                                  |
| ------------------------ | --------- | ---------------------------------------- |
| `--tabs-indicator-color` | Indicator | The primary color, `--kova-primary` when set |

## Accessibility

It follows the [WAI-ARIA tabs pattern](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/). See the [accessibility reference](https://ui-sdk.dev/docs/react/components/tabs#accessibility) for every key and the tested behavior.

- Name the list with `aria-label`, or `aria-labelledby` when a visible heading describes it.
- The selected tab shows with an underline and a heavier label, not color alone. Each panel is labelled by its tab.
- Icons in `Tabs.TabIcon` are hidden from screen readers, so an icon-only tab needs an `aria-label`.
