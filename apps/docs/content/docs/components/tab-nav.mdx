Use a TabNav for a row of links between related pages, like a project's overview, members and settings, where each tab has its own URL. It's a navigation landmark of links, not a tab list, and the current page is marked with `aria-current="page"`. For panels on the same page, use [Tabs](/docs/components/tabs).

<Preview name="tab-nav/basic" />

## Usage

```tsx
import { TabNav } from "kova-ui/components"

function Example() {
  return (
    <TabNav aria-label="Project">
      <TabNav.Link href="/overview" current>
        Overview
      </TabNav.Link>
      <TabNav.Link href="/settings">Settings</TabNav.Link>
    </TabNav>
  )
}
```

## Icons and counters

Put an icon in a `TabNav.LinkIcon` before the label, and a count in `counter`. Icons hide below `hideIconsBreakpoint`, 48rem of container width by default. Pass `null` to keep them. Give every link an icon, or none.

<Preview name="tab-nav/icons-counters" />

## Loading counters

Set `loadingCounters` while the counts load. Every counter shows loading dots until all are ready.

<Preview name="tab-nav/loading-counters" />

## Overflow

Links that don't fit move into the **More** panel. When the current page is one of them, the More button is underlined and says so to screen readers.

<Preview name="tab-nav/overflow" />

## Flush

`variant="flush"` lines the links up with the content above and below, instead of insetting them.

<Preview name="tab-nav/flush" />

## Router links

Relative links render the `linkComponent` from [KovaProvider](/docs/components/kova-provider), and links to `http(s)://` URLs open in a new tab. Pass `render` to use another component for one link, like `render={<Link to="/settings" />}`. Derive `current` from the router's location.

## API Reference

### TabNav

Renders a `<nav>` landmark with the list of links, and the More panel when links overflow.

| Prop                  | Type                                                                   | Default    | Description                                                     |
| --------------------- | ---------------------------------------------------------------------- | ---------- | --------------------------------------------------------------- |
| `aria-label`          | `string`                                                               |            | Names the navigation. Required unless `aria-labelledby` is set. |
| `variant`             | `"inset" \| "flush"`                                                   | `"inset"`  | Insets the links from the edges, or lines them up with them.    |
| `loadingCounters`     | `boolean`                                                              | `false`    | Shows loading dots in every counter.                            |
| `hideIconsBreakpoint` | `"xsmall" \| "small" \| "medium" \| "large" \| "xlarge" \| "xxlarge" \| null` | `"medium"` | Container width below which icons hide.                  |
| `moreLabel`           | `string`                                                               | `"More"`   | The label of the button that holds overflowing links.           |

### TabNav.Link

Renders a list item with an `<a>`.

| Prop        | Type                                              | Default  | Description                                                        |
| ----------- | ------------------------------------------------- | -------- | ------------------------------------------------------------------ |
| `href`      | `string`                                          |          | Where the link goes.                                               |
| `current`   | `boolean`                                         | `false`  | Marks the current page with `aria-current="page"`.                 |
| `counter`   | `number \| string`                                |          | A count shown in a badge after the label.                          |
| `external`  | `boolean`                                         | Detected | Opens in a new tab. Detected from `http(s)://` URLs.               |

### TabNav.LinkIcon

Renders a `<span>` for a decorative icon before the label. `mirror` flips a directional icon in right-to-left text.

### Data attributes

TabNav is built on NavigationMenu. Its parts carry their state as data attributes, like `data-current` on the current page's link, and a `data-slot`, like `navigation-menu-link`. Kova styles from them, and so can you. See [data attributes](https://ui-sdk.dev/docs/react/components/navigation-menu#data-attributes) for the full list and the CSS variables, like `--available-height`. `TabNav` is `NavigationMenu`, `TabNav.Link` is `NavigationMenuLink` and `TabNav.LinkIcon` is `NavigationMenuLinkIcon`. The More button is a `NavigationMenuTrigger`, and its panel a `NavigationMenuContent`.

Kova adds:

| Attribute                    | Values                                                                   | Description                                                                 |
| ---------------------------- | ------------------------------------------------------------------------ | --------------------------------------------------------------------------- |
| `data-variant`               | `"inset" \| "flush"`                                                     | On `TabNav`, its `variant`.                                                 |
| `data-hide-icons-breakpoint` | `"xsmall" \| "small" \| "medium" \| "large" \| "xlarge" \| "xxlarge"` | On `TabNav`, the breakpoint below which icons hide. Left out when `null`.   |
| `data-current`               |                                                                          | On the More button, while its panel holds the current page's link.          |

### CSS variables

| Variable                 | Default                            |
| ------------------------ | ---------------------------------- |
| `--tabs-indicator-color` | The primary color, `--kova-primary` when set |

## Accessibility

It follows the [disclosure navigation pattern](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/examples/disclosure-navigation/). See the [accessibility reference](https://ui-sdk.dev/docs/react/components/navigation-menu#accessibility) for every key and the tested behavior. TabNav renders a named landmark holding a list of links, and a button that shows the overflowing ones.

- Name each TabNav with `aria-label`, so screen reader users can tell landmarks apart.
- Mark exactly one link `current`. It shows with an underline and a heavier label, not color alone.
- Links that overflow are hidden from the row and from screen readers, and listed in the More panel instead.
