title: Image
description: Fade a remote image in once it loads, and remove it if it fails.

Image is an `<img>` that stays transparent until it has loaded, then fades in. An image that fails to load is removed instead of showing the browser's broken image icon, and an image that has loaded once appears at once on later renders. For profile pictures, use [Avatar](/docs/components/avatar), which falls back to initials or an icon.

<Preview name="image/basic" />

## Usage

```tsx
import { Image } from "kova-ui/components"

function Example() {
  return <Image src="/photos/valley.jpg" alt="A forested valley" className="h-50 w-80 object-cover" />
}
```

## Fade in

Each new `src` fades in when it finishes loading. Give the image, or a placeholder around it, a fixed size so the layout doesn't move while it loads.

<Preview name="image/fade-in" />

## Failed to load

An image that fails to load renders nothing, so keep a placeholder in the layout around it. Set `forceRenderAfterLoadFail` to keep the `<img>` in the page anyway.

<Preview name="image/failed" />

## API Reference

### Image

Renders an `<img>`, or nothing when `src` is empty or the image failed to load. It takes every `<img>` attribute.

| Prop                       | Type                  | Default | Description                                                   |
| -------------------------- | --------------------- | ------- | ------------------------------------------------------------- |
| `src`                      | `string`              |         | The image URL. Without it, nothing renders.                   |
| `alt`                      | `string`              |         | The text alternative. Use `""` for a decorative image.        |
| `forceRenderAfterLoadFail` | `boolean`             | `false` | Keeps the `<img>` after it fails, showing the broken image.   |
| `draggable`                | `boolean`             | `false` | Lets the image be dragged.                                    |
| `onLoad`                   | `(event) => void`     |         | Runs once it loads, after it's marked as loaded.              |
| `onError`                  | `(event) => void`     |         | Runs when it fails to load.                                   |

### Data attributes

| Attribute     | Present when                                                  |
| ------------- | ------------------------------------------------------------- |
| `data-loaded` | It has loaded, or failed with `forceRenderAfterLoadFail` set. |

The image has `data-slot="image"`.

## Accessibility

- Always set `alt`. Describe the image, or use `alt=""` when it's decorative.
- A failed image is removed, so the text around it has to make sense without it.
- Images aren't draggable by default. Set `draggable` to allow it.
