---
title: Text Link
description: Link to a page from inside text, with your router or a plain anchor.
---

Use a text link to navigate from inside a sentence or a list of links. It renders your router's link for internal paths, set once on [KovaProvider](/docs/components/kova-provider), and an `<a>` that opens a new tab for external URLs. For a standalone action, use a [Button](/docs/components/button), or `ButtonLink` for a link that looks like one.

<Preview name="text-link/basic" />

## Usage

```tsx
import { TextLink } from "kova-ui/components"

function Example() {
  return <TextLink href="/settings">Settings</TextLink>
}
```

## Color from the text around it

A text link takes the color of the text around it and is underlined, so it differs from that text without a color of its own. On hover it fades a little, and inside `text-secondary` or `text-tertiary` text it darkens by one step instead.

<Preview name="text-link/inherit" />

## Primary

`primary` colors the link with the link color and drops the underline. Pass `underline` to keep it.

<Preview name="text-link/primary" />

## No underline

`underline={false}` removes the underline where the link is clearly a link already, like a row of footer links.

<Preview name="text-link/underline" />

## External links

A URL starting with `http://` or `https://` renders an `<a>` with `target="_blank"` and `rel="noopener noreferrer"`. Set `external` to treat any other URL the same way. Add an icon and hidden text so people know a new tab opens.

<Preview name="text-link/external" />

## Font weight

Set the weight with a class, or with `--link-font-weight` for every link.

<Preview name="text-link/weight" />

## Without a destination

Without `href` or `render`, a text link renders a `<button type="button">` that looks like a link, for an action inside text like showing details.

<Preview name="text-link/button" />

## Routers

Set your router's link once on `KovaProvider`, and every internal `TextLink` renders it. See [KovaProvider](/docs/components/kova-provider) for routers that navigate with `to`.

```tsx
import { KovaProvider, TextLink } from "kova-ui/components"

function App() {
  return (
    <KovaProvider linkComponent={RouterLink}>
      <TextLink href="/help">Get help</TextLink>
    </KovaProvider>
  )
}
```

For a single link, pass an element to `render` instead, as in `<TextLink render={<Link to="/dashboard" />}>Dashboard</TextLink>`. The element receives the link's props and children.

## API Reference

### TextLink

Renders the `KovaProvider` link component for internal paths, an `<a>` for external URLs, or a `<button>` without a destination. It takes every `<a>` attribute.

| Prop            | Type                          | Default                         | Description                                                   |
| --------------- | ----------------------------- | ------------------------------- | ------------------------------------------------------------- |
| `href`          | `string`                      |                                 | Where the link goes.                                          |
| `primary`       | `boolean`                     | `false`                         | Uses the link color and drops the underline.                  |
| `underline`     | `boolean`                     | `!primary`                      | Underlines the link.                                          |
| `external`      | `boolean`                     | Detected from the URL           | Opens the link in a new tab.                                  |
| `onClick`       | `(event) => void`             |                                 | Runs when it's pressed.                                       |

### Data attributes

| Attribute        | Present when           |
| ---------------- | ---------------------- |
| `data-primary`   | `primary` is set.      |
| `data-underline` | It's underlined.       |

The link has `data-slot="text-link"`.

### CSS variables

| Variable                           | Default                  |
| ---------------------------------- | ------------------------ |
| `--link-font-weight`               | `inherit`                |
| `--link-gap`                       | `spacing(0.5)`, between text and icon |
| `--link-radius`                    | `--radius-sm`, for the focus ring |
| `--link-underline-decoration-offset` | `0.1em`                |
| `--link-primary-text-color`        | `--color-link`           |
| `--link-primary-text-color-hover`  | `--color-link-hover`     |

## Accessibility

| Key     | Does                                                        |
| ------- | ----------------------------------------------------------- |
| `Tab`   | Moves focus to the link, which shows a focus ring.          |
| `Enter` | Follows the link, or runs the action of a link without one. |
| `Space` | Runs the action of a link without a destination.            |

- Write link text that makes sense on its own. Avoid "click here".
- Keep the underline for links inside paragraphs, so they aren't told apart by color alone.
- Say when a link opens a new tab, in its text or in hidden text beside an icon.
- A text link without a destination is a real button. Use it for small actions inside text. For anything else, use a [Button](/docs/components/button).
