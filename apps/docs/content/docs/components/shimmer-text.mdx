Shimmer text sweeps a soft highlight across its text, in the text's own color. Use it for a short status label while something loads or is being generated, like "Thinking…".

<Preview name="shimmer-text/basic" />

## Usage

```tsx
import { ShimmerText } from "kova-ui/components"

function Example() {
  return <ShimmerText>Thinking…</ShimmerText>
}
```

## Heading

`as` sets the element, like a heading. Typography comes from your own classes.

<Preview name="shimmer-text/heading" />

## Stopping the shimmer

When the same text stays on screen after the work ends, use `ShimmerableText` and toggle `shimmer`. The current sweep finishes before it stops, so it never cuts off halfway, and setting `shimmer` again starts it over.

<Preview name="shimmer-text/shimmerable" />

## API Reference

### ShimmerText

Renders a `<div>`, or the element `as` names, that always shimmers. It takes every attribute of that element.

| Prop        | Type                                                                      | Default | Description            |
| ----------- | ------------------------------------------------------------------------- | ------- | ---------------------- |
| `as`        | `"div" \| "span" \| "p" \| "h1" \| "h2" \| "h3" \| "h4" \| "h5" \| "h6"` | `"div"` | The element to render. |

### ShimmerableText

Renders like `ShimmerText`, and shimmers only while `shimmer` is set.

| Prop      | Type      | Default | Description                                                         |
| --------- | --------- | ------- | ------------------------------------------------------------------- |
| `shimmer` | `boolean` | `false` | Shimmers while true. Once false, the current sweep finishes first.  |
| `as`      | Same as `ShimmerText` | `"div"` | The element to render.                               |

### Data attributes

| Attribute   | Present when                                            |
| ----------- | ------------------------------------------------------- |
| `data-idle` | `ShimmerableText` isn't shimmering. Its animation is removed. |

Both carry `data-slot="shimmer-text"`.

## Accessibility

- The text stays plain text, so screen readers read it as usual. The shimmer is only visual.
- The shimmer announces nothing. Put the text in a `role="status"` region when the change needs announcing.
- The highlight is a gradient over the text's own color, so contrast stays close to the plain text.
- Shimmer one status label, not every row of a list.
