title: TransitionGroup

TransitionGroup is the primitive under [Animate](/docs/transitions/animate) and [AnimateLayout](/docs/transitions/animate-layout). It keeps a child in the page while it leaves, and marks each stage of its entrance and exit with data attributes. It adds no styles, so you write the transition. Reach for Animate or AnimateLayout first, and use TransitionGroup for transitions they can't describe. [SlotTransitionGroup](/docs/transitions/slot-transition-group) does the same without wrapper elements.

## Usage

```tsx
import { TransitionGroup } from "kova-ui/components"
import s from "./Example.module.css"

function Example({ visible }: { visible: boolean }) {
  return (
    <TransitionGroup className={s.Item} enterDuration={300} exitDuration={200}>
      {visible && <Card key="card" />}
    </TransitionGroup>
  )
}
```

```css
.Item {
  transition: opacity 300ms ease;

  &[data-entering]:not([data-entering-active]),
  &[data-exiting-active] {
    opacity: 0;
  }
}
```

## Entering on mount

Children present when the group first renders don't transition. Pass `preventInitialTransition={false}` to have them enter too.

```tsx
<TransitionGroup preventInitialTransition={false} enterDuration={300}>
  {visible && <Card key="card" />}
</TransitionGroup>
```

## API Reference

### TransitionGroup

Renders no element of its own. Each child is wrapped in a `<span>` (or the `as` element) that carries the attributes.

| Prop                       | Type                     | Default    | Description                                                         |
| -------------------------- | ------------------------ | ---------- | ------------------------------------------------------------------- |
| `children`                 | `ReactNode`              |            | Children, each with a stable `key`. A child without one throws.     |
| `enterDuration`            | `number`                 | `0`        | How long the entering attributes stay, in milliseconds.             |
| `exitDuration`             | `number`                 | `0`        | How long a leaving child stays before it's removed, in milliseconds. |
| `preventInitialTransition` | `boolean`                | `true`     | Skips the entrance of children present on the first render.         |
| `enterMountDelay`          | `number`                 |            | Waits this many milliseconds before mounting a new child.           |
| `insertMethod`             | `"append" \| "prepend"`  | `"append"` | Where a new child goes relative to leaving ones.                    |
| `disableAnimations`        | `boolean`                | `false`, `true` in tests | Renders changes at once, with no attributes.          |
| `as`                       | `"span" \| "div"`        | `"span"`   | The element of each child's wrapper.                                |
| `style`                    | `CSSProperties`          |            | Styles on each child's wrapper.                                     |
| `transitionId`             | `string`                 |            | Set as `data-transition-id` on each wrapper.                        |
| `ref`                      | `Ref`                    |            | The wrapper, when there is a single child.                          |
| `onEnter`, `onEnterActive`, `onEnterComplete` | `(element) => void` | | Run as an entrance is staged, starts and ends.             |
| `onExit`, `onExitActive`, `onExitComplete`    | `(element) => void` | | Run as an exit is staged, starts and ends.                 |

### Data attributes

The attributes appear only while they apply.

| Attribute              | Present when                                                                 |
| ---------------------- | ---------------------------------------------------------------------------- |
| `data-entering`        | The child is entering, from the frame before the transition until it ends. Stage the starting style here. |
| `data-entering-active` | The entrance is running.                                                     |
| `data-exiting`         | The child is leaving, from the frame before the transition until it's removed. |
| `data-exiting-active`  | The exit is running.                                                         |
| `data-interrupted`     | The child reversed before its transition ended, like a leaving child shown again. |

## Accessibility

- It adds no roles or ARIA attributes. Its wrappers are plain `<span>` or `<div>` elements.
- A leaving child stays in the page for `exitDuration`. Move focus out before removing content that has it.
- Motion isn't reduced automatically. Pass `disableAnimations` when `prefers-reduced-motion` is set, or remove the transition in your CSS.
