## Examples

### Variants
Use `variant` to stylize the textarea.

<Canvas of={TextareaStories.Variants} sourceState="none" />

### Auto resize

Enable `autoResize` to automatically grow/shrink the textarea as the user types. Control the bounds with `rows` (initial height) and `maxRows`.

<Canvas of={TextareaStories.AutoResize} />

### Sizing

Sizing of the textarea is controlled with `size` and `gutterSize` props. `size` sets the textarea to a specific control `height` for single-line equivalent, and `gutterSize` sets the horizontal padding.

Each `size` provides default values for `gutterSize`, as well as `font-size` and `border-radius`. Each of these values can be overridden independently.

<Canvas of={TextareaStories.Sizing} sourceState='hidden' />

### Disabled

Use the `disabled` prop to disable the textarea, greying it out and preventing user interactions.

<Canvas of={TextareaStories.Disabled} />

### Invalid

Use the `invalid` prop to mark the textarea as invalid. You decide how this state is removed, whether that's through `onFocus`, `onChange`, an `onSubmit` handler, etc.

Default visual styles will be applied, based on the `variant`. Additionally, `[data-invalid]` is applied to the container for custom styling.

<Canvas of={TextareaStories.Invalid} />

### Auto select text

Pass `autoSelect` to select all the text in the textarea, which is handy next to a copy action. This prop behaves like an imperative action when toggled and allows selection to change.

<Canvas of={TextareaStories.AutoSelect} />

### Autofill extensions

By default, autofill extensions are prevented by `Textarea`. For the occasions where you want browser extensions to be present, pass `allowAutofillExtensions` to remove the disabling.

When `name` is passed this value will default to `true`.

<Canvas of={TextareaStories.AutofillExtensions} />

## Best practices

- Pair every `Textarea` with a visible label. Do not rely on `placeholder` alone.
- Use `autoResize` with `maxRows` for chat or comment fields so the field grows without taking over the page.
- Match `size` and `variant` to nearby `Input` and `Select` controls in the same form.
- Show an error message next to the field when you set `invalid`, and clear it when the input becomes valid.
- Pass `name` or `allowAutofillExtensions` only when password managers or autofill should appear.

## Accessibility

- Renders a native `textarea`, so focus, selection, and keyboard behavior follow the browser.
- Pass `id` and connect it to a `<label htmlFor>`. Without `id` or `allowAutofillExtensions`, an internal id is generated to block password managers, so labels must use your own `id`.
- `invalid` changes only the styles. Also set `aria-invalid` and link the error text with `aria-describedby`.
- `disabled` and `readOnly` are passed to the native element, so assistive technologies announce them.
