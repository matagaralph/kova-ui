ShimmerText sweeps a soft highlight across its text, in the text's own color. Use it for short status labels while something is loading or being generated.

## Usage
```jsx
import { ShimmerText } from "kova-ui/components";
```

### Stopping the shimmer
When the text should stop shimmering once work finishes, use `ShimmerableText` and toggle `shimmer`. The current sweep finishes before the animation stops, so it never cuts off mid-way. Setting `shimmer` again restarts it.

<Canvas of={ShimmerTextStories.Shimmerable} />

## Best practices

- Keep shimmering text short, like "Thinking…" or "Loading results".
- Use `ShimmerText` when the text is removed once loading ends, and `ShimmerableText` when the same text stays on screen afterwards.
- Avoid shimmering many items at once. Shimmer one status label rather than every row.

## Accessibility

- The text stays in the DOM as plain text, so screen readers read it normally. The shimmer is purely visual.
- The shimmer doesn't announce changes. Pair it with a `role="status"` region when the loading state needs to be announced.
- The highlight is a gradient over the text's own color, so contrast stays close to the original text.
