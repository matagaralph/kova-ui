## Examples

### Text

For text-based avatars, a single initial is displayed based on the `name` prop passed to the component.

<Canvas of={AvatarStories.Text} />

### Image
To display an image avatar, provide an absolute URL to the image with `imageUrl`. Images will have a soft fade entrance once loaded, or fallback to a text display if the image fail to load.
<Canvas of={AvatarStories.Image} />

### Icon
To display an icon avatar, provide an icon to render to the `Icon` prop. The `name` prop is not used in this case, and can be omitted.
{/* Providing a custom source because it's struggling to render the SVG prop correctly. */}
<Canvas of={AvatarStories.Icon} source={{code:`<Avatar
  Icon={Headphones}
  size={48}
/>`}} />

### Overflow count
To display an overflow avatar, provide a number to the `overflowCount` prop. The number will be automatically formatted and scaled to fit.
<Canvas of={AvatarStories.Overflow} />

### Sizing
To size the avatar, pass a `number` to the `size` property, which will set the width and height in pixels. Text and icon avatars will scale their sizes dynamically based on this value.
<Canvas of={AvatarStories.Sizing} />

### Colors & variants
You can stylize the display of the avatar using the `color` and `variant` props.
{/* Providing a custom source because it's struggling to render the SVG prop correctly. */}
<Canvas of={AvatarStories.Colors} sourceState="none" />

### Roundness
By default, avatars are fully rounded. You can override this by passing a Tailwind rounding class to `className`.

<Canvas of={AvatarStories.Rounding} />

### Interactive
Avatars can be used as interactive elements by passing an `onClick` handler. The avatar will automatically apply semantic and visual interaction styles.

/>`}} />

## Best practices

- Use a single `<Avatar>` for one person or entity. Use `<AvatarGroup>` to show several together.
- Always pass `name`, even with `imageUrl`, so the initial is shown if the image fails to load.
- Use `Icon` for non-person entities like bots or teams, and `overflowCount` only for summarizing hidden items in a group.
- Keep `color` and `variant` consistent for the same entity across a product.
- Only pass `onClick` when the avatar triggers an action, such as opening a profile menu.

## Accessibility

- Non-interactive avatars render with `role="presentation"`, and images use an empty `alt`, so assistive technology ignores them. Show the person's name in nearby text when it matters.
- Passing `onClick` or `onPointerDown` renders a native `<button type="button">`, which is focusable and activates with Enter and Space.
- An interactive avatar's accessible name is only the displayed initial, so pair it with visible text or a `<Tooltip>` that identifies the person.
