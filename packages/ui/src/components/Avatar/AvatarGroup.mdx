## Best practices

- Use `<AvatarGroup>` to show a small set of people at a glance, such as collaborators or participants.
- Limit the visible avatars and summarize the rest with an `<Avatar overflowCount={n} />` as the last child.
- Set `size` on the group instead of on each `<Avatar>` to keep sizing consistent.
- Use `stack="start"` (default) to keep the first avatar on top, or `stack="end"` to layer later avatars above earlier ones.

## Accessibility

- The group is a plain `<div>` with no role, and non-interactive avatars are hidden from assistive technology. Provide the list of names in nearby text or a `<Tooltip>` when it matters.
- Interactive avatars inside the group remain native buttons and follow normal tab order.
