## Usage
```jsx
import { LayerCard } from "kova-ui/components";
```

Use `LayerCard.Secondary` for the header row and `LayerCard.Primary` for the main content to get the layered treatment.

### Custom element
`LayerCard` is built on Base UI's `useRender`, so the `render` prop swaps the root element while keeping its styles. For example, make the whole card a link:

```jsx
<LayerCard render={<a href="/docs/getting-started" />}>
  <LayerCard.Secondary>Getting Started</LayerCard.Secondary>
  <LayerCard.Primary>Quick start guide for new users</LayerCard.Primary>
</LayerCard>
```

## Best practices

- Use `LayerCard.Secondary` for a short label or header and `LayerCard.Primary` for the main content. Render children directly for a plain surface card.
- Keep `LayerCard.Secondary` to a single line, such as a title or a row of filters.
- Make the whole card interactive with `render` (e.g. an `a` element) rather than nesting a link inside.
- Avoid placing multiple interactive elements inside a card that is itself a link.

## Accessibility

- Renders a `div` with no role by default. Use `render` to change the root to a semantic element such as `a`, `section`, or `article`.
- When the card is a link, its full text becomes the link's accessible name. Keep the content concise, or add an `aria-label`.
- Props such as `aria-*` and `role` pass through to the root, `LayerCard.Primary`, and `LayerCard.Secondary`.
